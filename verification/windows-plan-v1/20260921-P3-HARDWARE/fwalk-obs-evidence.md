结论：
- **H2 假说升级为主假说**：弹回与 FBP winrt 连接状态崩塌强相关——第二次弹回的「发现 0 个服务」（重发现失败=连接已失效）紧前于 dispose；两次弹回均无「断开（用户操作）」日志（排除误点断开按钮）。
- **代码层无自动 pop 路径**（全仓枚举在案），路由回退疑似 FBP 连接事件链→Navigator 异常路径；FBP 层 debugPrint 不上屏幕，精确定位需 F 侧日志基建（下轮）。
- 修复方向（交下轮）：详情页对断连/重发现空应显示错误态+重试（已有 _buildErrorView），而非路由回退；P006 连接韧性加固。
