# 产品理解（E1 静态审计）

## 产品定位

**推断：**BLE Toolkit+ 是面向开发者、硬件调试人员与 Smart HID 用户的多平台 BLE 工具；微信小程序端提供“附近设备扫描 → 通用 GATT 调试”及“Smart HID 专属配网”两条路径。它不是面向普通消费者的泛 IoT 控制器。

核心价值是无安装门槛地查看附近 BLE 广播、连接并读写特征，以及完成 Smart HID 的一次性 BLE 配网。

## 用户角色

| 角色 | 目标 | 登录 |
|---|---|---|
| U01 BLE 调试者 | 扫描、查看广播、连接、读写、notify、OTA | 不需要 |
| U02 Smart HID 安装者 | 发现设备、扫码、下发 Wi-Fi/Hub 配置、确认 ready | 不需要；需蓝牙/相机权限 |
| U03 已配置设备维护者 | 看历史资料、重新配置、诊断 | 不需要；诊断需要重连 BLE |

## 核心任务

| ID | 任务 | 起点 → 完成条件 | 主要失败 |
|---|---|---|---|
| T01 | 通用 BLE 调试 | 设备 Tab → 扫描 → 设备详情 → 服务/读写/通知 | 蓝牙未开、权限拒绝、扫描/连接失败 |
| T02 | 查看广播 | 扫描结果 → 卡片 → 广播 Snapshot | 平台未提供字段、工具未展示字段 |
| T03 | Smart HID 配网 | HID → 配置 → 扫设备 → 验证 → 扫二维码 → Wi-Fi → 下发 → ready | 扫描、配对、Wi-Fi、Hub、MQTT、NVS 失败 |
| T04 | Smart HID 故障恢复 | HID 历史 → 详情 → 诊断/重新配置 | 没有现存 BLE session，诊断不可执行 |

## 非目标/边界

- V1 不通过 BLE 做实时 HID 控制。
- 不存在登录、支付、订单、云端内容、用户账号业务；相应状态为**不适用**而非“缺失”。
- 微信小程序的外设广播能力须按平台 API 实际能力降级，不可承诺等同原生 App。
