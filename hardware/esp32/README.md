# Smart BLE ESP32 Fixtures

PlatformIO project root: `LightBLE/`.

## Environments

| Environment | Role | Description |
|---|---|---|
| `fixture_peripheral` | GATT server | Full LightBLE peripheral fixture (default build) |
| `fixture_observer` | Scan scaffold | Build-only observer stub (`ESP32-OBSERVER-001` implements behavior) |
| `esp32dev` | Alias | Backward-compatible alias of `fixture_peripheral` |

## Build

```bash
cd hardware/esp32/LightBLE
pio run                      # both fixture_peripheral + fixture_observer
pio run -e fixture_peripheral
pio run -e fixture_observer
```

Build metadata is generated by `scripts/build-info.py` into:

- `include/firmware_build_info.h` (`FW_VERSION`, `FW_GIT_SHA`, …)
- `build-metadata.json` (local build artifact; `build_time` is not used for reproducible comparisons)

## Serial ports (no fixed COM)

Do **not** hardcode `COM3` or `/dev/cu.*` in `platformio.ini`.

Optional environment variables:

```bash
export UPLOAD_PORT=/dev/cu.usbserial-XXXX   # macOS/Linux example
export MONITOR_PORT=/dev/cu.usbserial-XXXX
pio run -t upload -e fixture_peripheral
pio device monitor -b 115200
```

When unset, PlatformIO auto-detects the serial port.

## Flash

Upload is **manual** — this repository does not ship production flash scripts.
