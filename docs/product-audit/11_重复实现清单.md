# 重复实现清单

| ID | 类型 | 重复位置 | 当前问题 | 推荐方式 | 优先级 |
|---|---|---|---|---|---|
| RPT-01 | 状态/错误 UI | P005、P007、P002/P004 多套 error box/log | 文案、恢复动作、视觉结构各自实现 | 保持业务文案独立，抽 `operation-state`/error-banner action primitive | P4 |
| RPT-02 | 日志 UI | P005 `log-panel`、P007 页面内 log panel | P007 重写相同时间/类型/清空概念 | 抽可配置日志容器或让 `log-panel` 支持 header action | P4 |
| RPT-03 | 卡片样式 | 多页面内联渐变、边框、shadow、radius | 已有 design tokens 但大量固定 rgba/值 | 扩充 card/layout class；不抽业务卡片 | P5 |
| RPT-04 | 平台前置能力 | 扫描 permission service 与广播 Android 权限内联 | 权限策略、失败呈现无法横向一致 | 拆 `platform-permissions`，按 capability 提供接口 | P4 |
| RPT-05 | 设备详情导航 | P001/P006/P003 | 已有 `hid-navigation` 只覆盖 HID → GATT | 扩展统一 device-context serializer，限制 URL 长度 | P4 |

判断：未发现多套扫描 Runtime、重复 Smart HID transport 或多套会话 registry；这些高风险能力已合理收敛。
