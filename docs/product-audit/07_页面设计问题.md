## 2. 分主题归组

### 2.1 文案与真实性（D01/D03/D04/D10/D11）
产品的**诚实性整体优秀**（错误提示中文化、降级路径明示、READY 引导如实），但存在一批「看起来像状态、实际是装饰」的元素：静态「连接稳定」、success 色协议 chip、过时权限文案。原则应统一为：**页面上出现的每一个「状态」，必须对应真实数据源**。D01 文案重复为用户点名项，优先级最高。

### 2.2 信息密度与口径（D05/D09/D15）
计数口径不一致（已连接数 vs 列表）、同一信息重复展示（deviceId×2）、同一状态双处展示，都源于各区块独立取数。建议以 store 为单一事实源派生全部展示值。

### 2.3 空态与中间态（D07/D13）
空态图语义错位、进行中无中间态，属于「状态设计矩阵不完整」（详见 10_异常状态遗漏）。P005 的空态体系本身是全应用最好的，问题只在图的选择。

### 2.4 视觉体系（D17）
`about/version.vue` 内 3 处硬编码渐变是 token 体系（design-system.css）外的孤岛，其余八页已完成统一。属遗留打磨项。
