## 二、审计方法

每个页面按固定流程追踪运行链路，不盘点结构了事：

```
页面 → 组件 → 用户操作 → 事件函数 → composable/store → service → 平台 API
     → 状态变化 → 页面反馈（toast/modal/banner/状态灯）→ 页面跳转 → 次页刷新
```

判定口径：

- **✅ 闭环**：点击后有真实反馈且与产品预期一致
- **⚠️ 半闭环**：有反馈但信息不完整/误导，或路径可达但体验断裂
- **❌ 断链**：点击无反应、必失败、或跳转到不存在的目标
- **💀 假完成**：UI 存在但业务结果不成立（含"代码调了 API 但用户目标没达成"）
