## 3. 结构性观察

1. **没有「缺失主链路」级遗漏**：扫描、配网、历史、广播四大主链路全部真实存在。全部 P2 都属于「链路末端出口缺失」（反馈、下一步动作、可见性），修复成本低、收益直接。
2. **三处 P2 指向同一个根因**——失败/完成事件缺少 UI 表达：F01（扫描完成）、F05（权限失败）、F06（中途断开）都是「事件发生了但界面不说」。
3. **两处 P2 指向第二个根因**——出口设计：F02（诊断后）、F04（假按钮）都是「到了终点没有下一步」。按这两个根因归组修复（见 12_修复路线图 Phase 2），比逐条修更划算。
