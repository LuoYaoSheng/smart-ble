# 架构问题清单

## 优势

- `ble-runtime` 单一平台回调与 session 事实源。
- 扫描/连接/Smart HID waiter/广播校验/OTA 确认等待均有针对性单测。
- Smart HID 敏感密码/token 不持久化。
- 微信 central/peripheral 模式所有权清晰。
