# P006 通用设备详情（pages/device/detail）

> 基线 `bf5d17e`。GATT 调试器：服务/特征浏览、读/写/notify、OTA、通信日志、自动重连。
> 结论先行：**全功能真实闭环，是全 App 完成度最高的页面**；遗留 5 个小问题（OTA 选文件失败静默、死导入、导出≠导出、兼容死分支、配网特征无防护）。

## 1. 基本信息

```text
页面名称：设备详情（navigationBarTitleText）
页面路径：pages/device/detail
页面类型：普通页（工具页，出边 0，系统返回）
进入方式：P001 设备卡「连接」（通用设备与 Smart HID 设备共用）；P001 已连接 tab 卡片
退出方式：系统返回（onUnload 断开连接并更新列表状态）
是否依赖权限：蓝牙；OTA 需从聊天记录选文件（wx.chooseMessageFile）
是否依赖网络：否
```

## 2. 页面产品目的

给开发者/高级用户一台设备的完整 GATT 视图和原语操作（读/写/notify），配合日志面板做协议调试；支持 OTA 固件升级。是"工具箱"属性页面，不承担业务流程。

## 3. 信息结构

```text
通用设备详情
├── 设备面板：名称 + 连接状态点 + deviceId + （有 OTA 服务时）固件更新按钮
├── 操作行：清空日志 / 导出日志 / 连接设备↔断开连接（状态换色）
├── 服务与特征面板（service-panel）
│   ├── 头部：N 个服务 + 全部展开/收起
│   ├── 空态："服务还没加载完成"（未连接时）
│   └── 服务折叠项 ×N：名称（FIX-06：标准服务/特征显示中文名）+ UUID + 特征数
│       └── 特征 ×N：名称 + UUID + 能力按钮（读取/写入/监听↔停止监听，按 properties 条件渲染）
├── 日志面板（log-panel）：时间戳 + 类型 + 消息，自动滚底
├── 写入弹窗（write-dialog）：文本/HEX 单选 + 内容输入 + 发送中禁用
└── OTA 弹窗（ota-dialog）：聊天文件选择 + 进度 + 开始升级
```

## 5. 运行链路要点

```text
连接：connectBleDevice(deviceId, {timeout:10000}) → ensureAdapterReady（FIX-02 ✓）
     → 服务发现（含 FIX-06 名称填充）→ updateDeviceServices/ConnectionStatus → P001 已连接 tab 同步
断线：session.onDisconnect → 状态 false + 日志 + 非手动则 retryConnection
读写：全部经 ble-runtime 原语（session 校验/目标解析/错误抛出），错误 message 已 errors.js 中文化
日志：logger.subscribe(deviceId) 历史回放 + 增量推送 + 自动滚底
```

## 6. Store / 状态

- `connectedDevicesMap[deviceId]`：本页是唯一写入方（init/update services/status）——P001 已连接 tab 与"已连接 N 台"计数的唯一数据源（与 smart-hid 会话互不相识，见 P001-I04 口径问题）。
- 卸载即断开：调试页语义自洽，返回 P001 后设备移出已连接列表 ✓。
