## 2. 页面产品目的

配网完成后设备会停广播"消失"，此页是找回已配置设备的唯一本地入口：回看每台设备上次配的 Wi-Fi/Hub，进详情做管理，或删除不再使用的记录。

## 3. 信息结构

```text
历史页
├── 空态（knownDevices 空）："还没有配置过的设备" + 引导说明
├── 列表头卡："已配置设备 / N 台" + 关键诚实提示
│   "本地历史记录，非实时在线状态。READY 设备已关闭蓝牙广播，重新配置前需让设备进入配网模式。"
└── 记录卡 ×N：HID 标 + 名称 + deviceId（mono）+ 标签（Wi-Fi SSID / Hub 地址 / 配置日期）+ 移除按钮
```
