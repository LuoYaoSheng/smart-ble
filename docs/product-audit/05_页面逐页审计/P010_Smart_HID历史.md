# P010 Smart HID 历史（`pages/hid/history`）

## 目的与入口

用户从扫描页“已配置 Smart HID → 全部历史”进入，查看本机保存的非敏感设备记录；空列表可以返回扫描，有记录时可以进入 P003 详情或移除记录。

## 当前运行链路

`P001 → P010 → P003 → P010`。数据事实源是 `hid.knownDevices`，由 `smart_ble.smart_hid.known_devices.v1` 恢复；不保存 Wi-Fi 密码或配对 token。

## 状态与结论

- 空态：显示原因和“去扫描”动作。
- 有数据：展示设备名、ID、最近 Wi-Fi/Hub 和配置日期。
- 删除：确认后只移除本机记录，不改变设备配置。
- 页面和往返跳转已通过 2026-08-31 微信开发者工具自动化；真实设备在线状态不在本页承诺范围内。

最终结论：客户端页面与导航 PASS，设备真实性由 P003/P004 的真机连接验证负责。
