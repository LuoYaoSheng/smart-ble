# P008 关于（pages/about/index）

> 基线 `bf5d17e`。Tab 页。品牌信息 + 小程序导流 + 系统信息 + 相关链接 + 分享。
> 结论先行：**全操作闭环**（微信端外链"打不开就复制"的降级、跳小程序带 fail modal、分享带引导 toast，均为诚实实现）；主要问题是**功能特性清单不含 Smart HID 配网**——核心新能力在"关于"页不可见。

品牌呈现（名称/版本/简介）、向同开发者的其他小程序导流、提供官网/反馈/版本记录/分享入口。微信端受平台限制（无法直接开网页），一切外部动作降级为"复制链接"。
