# P005 通用设备详情

页面路径：`pages/device/detail`；类型：GATT 工具页。复核：2026-08-29。

## A. 页面目的
对任意 BLE 设备建立 GATT 会话，读写通知、导日志、条件触发 OTA。

## B. 页面信息结构
设备头 → 日志动作/连接按钮 → **服务树（条件渲染）** → 日志 → 写对话框 → OTA 对话框。

## C. 合理性
OTA 仅在有服务时露出，正确；无服务时主区空白，不合理。

## D. 用户操作（操作清单）

| 操作ID | UI入口 | 用户操作 | 触发代码 | 预期 | 实际 | 后续 |
|---|---|---|---|---|---|---|
| O1 | 连接/断开 | 切换连接 | `toggleConnection` / `connectDevice` | 会话建立或关闭 | PARTIAL：失败主要靠日志 | 本页 |

## F. 状态
有连接点/日志/OTA 进度；**缺**连接 loading、空服务、发现失败、手动重试 UI。

## G–I
路由 JSON → `ble` + registry；open/connect/discover/read/write/notify；文件 API。

## J. 关键链路

### O1 连接
```text
UI → connectDevice → ble-runtime.connectDevice → 发现服务 → bindPageSession → Store
失败 → 自动重连×3 + 日志
判定：PARTIAL — 服务 panel `v-if services.length>0` ← 第一断点 FAIL（空/加载不可见）
假设修复后：仍缺显式重试按钮；重连后订阅恢复待真机
```

### O7 OTA（2026-08-29）
```text
UI → OtaManager.startOta
→ MTU → subscribe STATUS → 分片 writeNoResponse
→ phase=confirm 等待 parseOtaStatusPayload
→ status=success → onSuccess「设备已确认升级成功」
→ timeout/error/cancel → onError，不调用 onSuccess
判定：客户端 PASS（单测覆盖）；端到端 PARTIAL（固件常无 status → 诚实超时）
第一断点（产品）：设备协议未实现时无法真正升级成功 ← 非假完成
```
