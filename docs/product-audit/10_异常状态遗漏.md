# 异常状态遗漏

| 场景 | 已实现 | 缺失/薄弱 | 影响 |
|---|---|---|---|
| 扫描授权 | 微信蓝牙/定位引导、错误条 | 非微信平台权限与系统蓝牙恢复待验 | 平台差异 |
| GATT 连接 | 日志、自动三次重连 | loading/失败卡、手动重试、无服务态 | 高 |
| GATT 读写/通知 | 写日志、写入发送中 | UI 缺细化错误与重试入口 | 中 |
| OTA 文件选择 | 读取失败状态 | chooseFile fail 仅 console；无类型/大小预检 | 高 |
| OTA 传输 | 进度、确认等待、超时/失败不报成功 | 设备无 status 时只能超时；无版本回读 | 中（假完成已除） |
| HID 扫码 | 无效码 modal | 取消、相机权限/硬件失败静默 | 中 |
| HID 配网 | Status 错误映射和恢复 | 60 秒不可取消；离页无确认 | 中 |
| 广播 | 微信 modal；App 校验/权限失败可见 | 插件真机参数形状待验 | 中（静默失败已除） |
| 外部链接 | 小程序 fail modal | 官网/反馈/H5 打开失败弱反馈 | 低 |
