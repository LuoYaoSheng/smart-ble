# UI 与交互规范漂移

| 维度 | 观察 | 影响 | 建议 |
|---|---|---|---|
| Design Token | `design-system.css` 定义完整 token，但页面仍反复内写相同渐变、rgba、shadow、radius | 后续改版易漂移 | 将高频 surface/border/shadow 升为 token/class，渐进迁移 |
| 导航 | P001/P006 用自定义 navbar，其他页用原生导航 | 有意的 Tab/二级页分层，但标题/安全区视觉可能不一致 | 明确导航规范和平台截图回归 |
| 错误恢复 | P001 有 error-banner 重试；P005 多为日志；P007 日志/modal；P002 error box | 同级失败的下一步不一致 | 统一“错误原因 + 建议 + 主恢复动作”模式 |
| 空态 | P001/P006 复用 empty-state；P005 因条件渲染没有空态 | 空态体验断裂 | 修复 P005，组件支持主动作 |
| 按钮可访问性 | 原生 `button` 使用普遍，文本明确 | 正向 | 真机检查 focus、target size、禁用态对比度和 screen reader 标签 |
| 颜色/对比度 | 浅色文字、渐变与小字号广泛存在 | 静态无法确认对比度 | 用真机截图和 WCAG 工具测关键状态；不宣称合规 |
