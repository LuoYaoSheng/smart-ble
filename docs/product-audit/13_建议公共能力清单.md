# 建议公共能力清单

| 能力 | 当前实现位置 | 当前问题 | 推荐归属 | 优先级 |
|---|---|---|---|---|
| 通用设备会话页面编排 | P005 | 连接、重连、session bind、日志、notify 控制集中在页面 | `composables/use-device-session.js` | P4 |
| 广播业务编排 | P007 | 826 行混合 UI、payload、Android 权限、原生插件和微信 server | `composables/use-broadcast.js` + `services/broadcast/*` | P4 |
| 平台权限 | scan permission、P007 | 仅扫描有 service；广播 Android 内联 | `services/platform-permissions.js` | P4 |
| OTA 事务 | `OtaManager` | 没有设备端 ACK/CRC/版本确认模型 | `services/ota/*`，定义状态机与协议 adapter | P1 |
| 设备上下文路由 | P001/P006/P003 | 设备对象 JSON 直接放 URL，重复序列化与尺寸风险 | `services/device-navigation.js` + Store/context ID | P4 |
