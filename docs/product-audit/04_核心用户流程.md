## F01 扫描发现 — OK

路径：`pages/index` → `use-ble-scan` → `bleStore.startScan` → `scan-session`。
hide/unload 停发现；失败有 modal。

## F02 通用连接 / GATT — 风险

路径：紧凑路由 + stash → `device/detail` → `use-device-session` → `ble-runtime`。
服务空/失败/重试 UI 已有。unload 不断开（为已连接 Tab 保留会话）。

## F03 Smart HID 识别进配网 — OK

Profile 匹配 → `hid/add` → `smartHid.connect`；Device Info 失败即断开。

## F04 配网 + 扫码 — OK（客户端）

先 waiter 再 write；取消/返回确认；失败恢复含重连重试。敏感字段不落盘。

## F05 诊断 — OK

可借配网连接；`ownsConnection` 才在 unload 断开。

## F06 历史 / knownDevices — OK

扫描页历史区 + 全部历史页；90 天 / 同 ID 最新 / ≤20。

## F07 已连接列表 — 风险

Smart HID 已 bind 并带 `profileId`；断开时同步 `smartHidService.disconnect`。
与通用 GATT 仍共享 runtime，高级 BLE 断开可能影响配网会话（产品已知）。

## F08 广播 — 待真机

≤31 字节校验拦截；hide 停播；插件/微信切模式待验。

## F09 OTA — 待真机

须等 `{status:success}`；传输中可取消；无 status 固件诚实超时。

## 交叉互斥（摘要）

- 扫描 ↔ 广播：有 central 连接时微信拒 peripheral
- 配网 ↔ 诊断：借连 OK
- 配网 ↔ 通用 GATT：共享 runtime；从 HID 详情进高级 BLE 需注意断开影响
- Tab：离开扫描停发现；离开广播停播；连接保持

## 真机验 Top 5（剩余）

1. Status 快路径 ready — waiter 不丢终态
2. OTA 有/无 status 固件
3. 广播 31 vs 32 字节 + 模式切换
4. 配网成功 → 详情 → 诊断（会话保留）
5. 已连接 Tab 往返 HID / 通用详情
