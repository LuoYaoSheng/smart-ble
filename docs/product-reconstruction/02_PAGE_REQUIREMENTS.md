# PAGE REQUIREMENTS

## PAGE-001 扫描页

目标：统一设备入口。

入口：App启动、扫描Tab。

功能：
- 开启蓝牙
- 扫描设备
- 展示RSSI/name/profile
- 查看广播
- 连接
- 特殊设备专属入口

设备卡片必须同时拥有：

1. 广播查看
2. 连接按钮
3. 特殊Profile按钮（仅匹配设备）

## 特殊设备卡片规则

特殊设备发现后，可以采用两种展示方式：

方式A：保持普通设备卡片样式，仅增加 Profile 标识和专属入口。

方式B：使用专属设备样式，突出设备品牌、状态和业务能力。

无论采用哪种视觉形式，必须满足：

- 保留普通 BLE 设备卡片全部能力。
- 保留广播查看入口。
- 保留连接入口。
- 保留通用 BLE Inspector 入口。
- 专属入口只是额外能力。
- 专属详情页面不能替代通用设备详情页面。

正确模型：

普通设备卡片
+
Profile 扩展能力
+
专属业务页面

## PAGE-002 Smart HID配置

目标：完成Smart HID专属配置。

数据来源：BLE Profile。

功能：连接、配置、状态、恢复。

## PAGE-005 Smart HID诊断

目标：读取实时诊断。

状态：在线、离线、检测中、失败。

## PAGE-006 通用设备详情

目标：所有BLE设备通用调试入口。

功能：
- 连接/断开
- 服务树
- 特征值
- Read
- Write
- Notify
- OTA
- 日志

## PAGE-007 已连接

目标：展示当前活动BLE Session。

不等于扫描列表。

## PAGE-008 广播

目标：App作为Peripheral广播。

功能：payload配置、启动停止、平台检查。

## PAGE-009 关于

目标：开源信息、平台能力、文档入口。
