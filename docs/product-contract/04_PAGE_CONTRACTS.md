# 页面契约

## 全局规则

- 顶层导航固定为：扫描、已连接、广播、关于。
- Smart HID 是设备 Profile，不占用独立 Tab。
- 页面标题不在正文重复；装饰内容不能挤走首屏主操作。
- 每个异步操作至少具备 idle、loading、error、success/complete 中适用的状态。
- 页面跳转只传稳定的设备身份字段；密码、token 和完整广播数据不得放入 URL。
- Android/iOS/微信可使用原生导航外观，但操作语义和页面编号保持一致。

## PAGE-001 扫描

**首屏结构**：产品/蓝牙状态 → 扫描控制与数量 → 已配置历史（有时显示）→ 设备列表 → 广播快照弹窗。

**操作**：开始/停止/重试扫描、展开筛选、点击卡片看广播、连接、Profile 任务、查看/移除历史。

**必须状态**：平台不支持、蓝牙关闭、权限拒绝、待开始、扫描中、无结果、筛选无结果、结果列表、扫描失败、已有连接。

**显示名规则**：`name → localName → AD 0x09/0x08 → Profile → 厂商 → 未命名 BLE · ID 后缀`。空名称不得覆盖已获得的有效名称。

## PAGE-002 Smart HID 配网

**阶段**：连接 → 填写配置 → 查看状态。三个阶段在同一页面，不拆成多页。

**操作**：自动/重新连接、输入 SSID/密码/Hub、扫码、下发、取消等待、恢复、查看设备、返回扫描。

**必须状态**：连接中、身份错误、连接失败、已连接、连接丢失、表单不完整、二维码取消/无效、下发中、四步进度、Ready、八类错误、超时、用户取消。

密码和 token 不显示在诊断、日志、历史、URL 或截图测试数据中。

## PAGE-003 Smart HID 详情

展示设备 ID、协议、固件和上次成功配置快照。必须标明这是历史记录，不代表当前在线。

操作：重新配置、实时诊断、高级 BLE。三条路都携带同一 deviceId，返回后仍是当前设备。

## PAGE-004 Smart HID 历史

空态提供“去扫描”。有数据时显示名称、ID、Wi-Fi、Hub、日期和“历史记录”说明。

操作：打开详情、移除本机记录。移除不改变设备配置，并要求确认。

## PAGE-005 Smart HID 诊断

诊断项固定为 BLE、Wi-Fi、ControlHub、控制连接、Ready。区分尚未检测、连接中、实时结果、离线和失败。

操作：重新检测、显示错误码、返回详情、重新配网。历史设备必须先重连；只有页面自己创建的连接才在离页时关闭。

## PAGE-006 通用设备详情

**结构**：设备身份/连接状态/OTA → 会话操作 → 服务与特征值树 → 通信日志 → 写入和 OTA 弹窗。

**操作**：连接/断开、手动重试、Read、TEXT/HEX Write、Notify、清空/导出日志、OTA。

**必须状态**：初始化、连接中、服务加载、空服务、连接失败、已连接、被动断开、重连中、重连耗尽、读写失败、Notify 失败、OTA 全状态。

## PAGE-007 已连接

仅展示活动会话，不混入扫描结果。空态解释从扫描页连接；多于一台时显示数量和批量断开。

设备卡片展示“当前已连接”，不能使用没有健康指标支持的“连接稳定”。点击按 Profile 路由到 PAGE-003 或 PAGE-006。

## PAGE-008 广播

**结构**：平台和支持状态 → payload 字段 → 平台设置 → 字节预算 → 开始/停止与检查支持 → 日志。

**必须状态**：未知、检查中、不支持、未就绪、已就绪、广播中、停止中、权限错误、蓝牙关闭、连接冲突、参数错误、启动/停止失败。

微信和 App 的字段允许不同，但相同字段语义一致；H5 明确不支持。

## PAGE-009 关于

展示当前真实版本、开源定位、平台状态、核心能力、官网、仓库、文档、ESP32 教程、问题反馈和分享。其他小程序推广不得压过产品与开源信息。

平台不应显示未经验证的“完整支持”。

## PAGE-010 版本记录

首项版本必须等于运行时版本。每项包含发布日期和新增/修复/优化；页面进入时回到顶部，可返回 PAGE-009。

## HTML 原型要求

每个 PAGE 页面在原型中至少提供：正常态、一个关键空态、一个关键失败态和平台差异态。原型中的按钮必须实际切换页面或状态，不允许只有视觉无行为。
