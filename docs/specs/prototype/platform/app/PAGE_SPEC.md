## 1. 页面集

P001–P010（无 PAGE004）同基准；`low-fi/index.html` 线框含每页「平台差异注入点」标注。

## 2. 各页 Android 差异行

| 页 | 基准行为 | Android 差异（覆写） |
|---|---|---|
| P001 扫描 | 首次扫描即扫（权限态为微信授权口径） | 首次扫描触发 FINE_LOCATION 系统弹窗；拒绝→横幅（`bluetooth_permission_denied`）；二次拒绝→永久拒绝→仅剩清单引导；蓝牙关闭→Intent 系统蓝牙设置→回流自动续扫 |
| P002 配网 | 下发直接进入四行进度 | 首次加密写触发系统配对弹窗（PIN）；配对成功→基线进度；取消→2s 自动重试一次；再取消→失败 modal（重新下发；二次策略【未知】） |
| P003/P005/P007 | 同基准 | 无差异（会话/诊断/多设备逻辑平台无关） |
| P006 GATT | 日志导出=剪贴板 toast | 系统分享面板（复制/分享；「保存为文件」候选拦截） |
| P008 广播 | platform=android 静态分支（基线已含模式/功率字段与「实际用系统蓝牙名」提示） | 覆写层激活：模式/功率 picker 可交互（三档低耗·平衡·低延迟 / 四档功率）；注入三开关（可连接·不占预算 / 包含名称 / 添加 UUID）实时参与 31B 预算；启动前置权限链；超限按开关口径拦截 |
| P009 关于 | 外链复制 / 分享引导右上角 | 外链→拉起系统浏览器（还原图层）；分享→系统分享面板 |
| P010 版本 | 同基准 | 无差异 |

## 3. 补充态登记（STATE_MODEL §3 合法位置）

- P001：`bluetooth_permission_denied`（平台补充态，恢复动作=允许/去设置）
- P008：权限缺失汇总（恢复=去系统设置）
- P002：系统配对取消（自动重试一次 → 失败恢复路由）
