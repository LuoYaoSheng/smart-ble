## 1. 页面集

P001–P010（无 PAGE004）同基准；窗体为桌面窗口 chrome（740×600 演示窗口 + 标题栏 + 关闭钮）。`low-fi/index.html` 线框含每页「平台差异注入点」标注。

## 2. 各页桌面差异行

| 页 | 基准行为 | 桌面差异（覆写） |
|---|---|---|
| P001 扫描 | 同基准 | 连续扫描列表不变（BLE 经原生层，选型待 spike）；无移动端运行时权限环节 |

| P003/P005/P007 | 同基准 | 无差异 |
| P006 GATT | 单列纵排 + 底部日志 dock | **三栏重排**（左服务 / 中操作 / 右日志常驻，SOP §12 布局调整）；其余流程同基准 |
| P008 广播 | 同基准 | 平台徽标注 `Desktop · {OS}`；页首注入原生层提示（mac/win=info / linux=warn BlueZ【待验证】）；check/start 日志覆写标注原生层与待验证口径；界面/状态机同基准 |

| P010 版本 | 同基准 | 无差异 |

## 3. 窗口级规格（演示 · 操作系统三形态，2026-09-03 OS 维度）

| OS | 标题栏形态 | 关闭语义 |
|---|---|---|
| macOS（默认） | 左上交通灯（红=关闭）+ 居中标题 | 红/✕ → 退出确认 modal |
| Windows | 左对齐标题 + 右侧 ─ ▢ ✕ | ✕ → 退出确认 modal |
| Linux（GNOME 示意） | 左对齐标题 + 右侧仅 ✕ | ✕ → 退出确认 modal |

关闭 → 退出确认 modal（活动连接/广播时明示「断开会话并停止监听」；确认后断开并提示）。**窗控样式为平台还原图层**（COMPONENT_RULE §2），实际由操作系统渲染。评审栏另有「生态能力矩阵」卡（11_ecosystem，随 OS 随动，C2 待验证标注）。
