# PLATFORM_SPEC · Web（「GATT 调试器」子集 · D3=开发暂缓，原型先行）

> 平台设计说明之一 · 依据《平台设计说明规范 v1.0》§3 · 2026-09-03
> 三引用：① 基准 = [prototype/v1-new](../../v1-new/) ② 能力/限制 = [10_platform §2.3](../../../10_platform/PLATFORM_EXTENSION.md) ③ 差异设计 = 10_platform §4 Web 列。
> 排期口径：**原型齐备 ≠ 开发排期**——D3=暂缓（b）不变；本实例是子集形态的先行演示，供未来决策参考。

## 1. 平台定位

S1 扫描与 S4 广播两条核心旅程在浏览器断裂（无自由扫描 / 无外围 API），Web 只能承载「**已知设备的 GATT 调试器**」子集；缺失域**显式 ✗ + 指引发小程序/App**（10_platform §7 检查 1，延续基准 P008 U-03 口径）。

## 2. 优势 / 限制（10_platform §2.3）

- **优势**：零安装 URL 直达（U4 教学场景）；桌面浏览器大屏适合日志阅读。
- **限制（硬约束，公开技术事实）**：
  - 无自由扫描：仅 `requestDevice` 选择器（过滤→系统弹窗单选）；watchAdvertisements 实验性【待验证】；
  - 无广播发射：LE Advertising 无稳定 API【实验性，2026 状态待验证】；
  - GATT 域可用：连接后 read / write / startNotifications 完整；
  - 仅安全上下文（HTTPS）；兼容分化：Chrome/Edge 完整、Firefox ✗、Safari 桌面有限【待验证】、iOS 全系 ✗。

## 3. 交互方式

| 交互 | Web 形态 |
|---|---|
| 设备发现 | 选择器（过滤→单选→选择即授权，无运行时权限弹窗） |
| 权限模型 | 环境门禁（HTTPS + 浏览器支持 + getAvailability），失败显式横幅 |
| 分享 | 复制 URL（无社交面板） |
| 扫码 | —（S2 不可达，指引页） |
| 日志导出 | 剪贴板 / 下载 .txt |
| 生命周期 | 页签可见性守则（hidden 保持连接、暂停 UI，不静默断开） |
