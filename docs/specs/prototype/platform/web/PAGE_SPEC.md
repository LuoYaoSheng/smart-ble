## 2. 域可用性口径（stword 徽章，沿用 09_test 状态词）

`VERIFIED`=✅（S1b）· `UNSUPPORTED`=✗（S1a 仅选择器 / S4 / S2S3 / 环境不满足联动）· `PREVIEW`=△待验证（S6 单连接为主）· `BLOCKED`=同基准（S5 OTA，P-03）。环境不满足（HTTP / Firefox）时全域联动降为 UNSUPPORTED。

## 3. 演示值登记（禁止脑补）

GATT 服务树（FFF0/180F/180A）与读写返回值为**演示值**，正典以基准 v1-new P006 服务树为准；requestDevice 设备清单为演示数据；下载条/地址栏为浏览器还原层。
