## 1. S1–S6 与微信插入点

| 旅程 | 微信平台插入点（其余同基准） |
|---|---|
| S1 扫描发现 → GATT | 首次扫描触发**微信蓝牙授权弹窗**（拒绝 → 引导去设置）；后台/离开页面即停扫 |
| S2 SHID 配网 | uni.scanCode 扫配对码；V1 简化各平台均无系统配对环节；后台挂起时连接断开按基准断线恢复 |
| S3 故障排查 | 同基准（诊断五项） |
| S4 广播验证 | platform=weixin 分支：三档功率；开发者工具不支持 → 真机提示；活动连接冲突拦截 |
| S5 OTA | 同基准 12 态（端到端 BLOCKED P-03 不变） |
| S6 多设备会话 | 同基准（单台/批量断开 + 失败清单） |

## 2. 生命周期守则（BR-06 微信表达）

onUnload / 后台挂起 → 停扫、停广播、停监听；重进页面按各状态机基线恢复（自动重连不越过 BR-08）。

## 3. 出口流程

分享 → 客户端菜单（社交卡片）；外链 → 复制剪贴板；日志导出 → 剪贴板。
