## 2. 微信形态注记（差异映射）

| 基准元素 | 微信形态落点 |
|---|---|
| 自定义导航 navbar | 页面自绘（基准样式）；右上角为**客户端胶囊**（系统层，页面不绘制——high-fi 以 wx.css 示意） |
| P001 权限态 | 微信蓝牙授权弹窗 + 「去设置」（基准六态内置，无需覆写） |
| P001 SHID 设备卡 | 基准 v1.0.1：配置 Smart HID + 标准「连接」双入口（特殊设备 = 标准设备的扩展） |
| P008 平台分支 | `platform:'weixin'`：三档功率映射；平台徽标注宿主（微信 · iOS/安卓真机/开发者工具，wxhost.js） |
| P008 开发者工具宿主 | 真机调试横幅 + 检查支持→不支持 + 启动拦截（wxhost.js，旧代码 isWeixinDevTools 口径） |
| P009 宿主系统 | 应用信息卡「宿主系统」切换入口（安卓/iOS 真机/开发者工具；当前环境与设备型号随动）——wxhost.js |
| P009 分享 F029 | 「请点击右上角 · 分享给朋友或朋友圈」（触发客户端菜单） |
| P009 外链 | 复制到剪贴板 + toast |
| 版本投影 F027 | 小程序 release-metadata 读取；失败回退构建内置（P009 verFallback 场景） |
