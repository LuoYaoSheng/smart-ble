# PLATFORM_SPEC · 微信小程序（基准平台 · P1）

> 平台设计说明之一 · 依据《平台设计说明规范 v1.0》§3 · 2026-09-03
> 三引用：① 基准 = [prototype/v1-new](../../v1-new/)（基准即实例） ② 能力/限制 = [10_platform §2.1](../../../10_platform/PLATFORM_EXTENSION.md) ③ 差异设计 = 10_platform §4 微信列。

## 1. 平台定位

微信小程序是本产品的**基准平台**（P1，D1 首批）：基准原型 v1-new 本身即按微信小程序形态（375×812、自定义导航 + 客户端胶囊、tabBar 四 tab）构建。因此本平台内核**字节复制零改动**——`high-fi/` 为基准产品整体落地，差异只在两处：系统层示意（客户端胶囊，wx.css）与**宿主系统维度覆写层**（wxhost.js，2026-09-03 用户走查修正）。

## 2. 宿主系统维度（2026-09-03 用户走查修正 · 旧代码事实）

微信小程序区分运行宿主，旧代码（`apps/uniapp`）已有此维度：

| 宿主 | 判定（开发口径） | 行为差异 |
|---|---|---|
| 安卓真机 | `wx.getDeviceInfo().platform === 'android'` | 与 iOS 同一 wx BLE API 路径，**行为一致**（旧代码 MP-WEIXIN 单一实现） |
| iOS 真机 | `platform === 'ios'` | 同上；关于页展示宿主 osName/机型（`pages/about/index.vue`） |
| 微信开发者工具 | `platform === 'devtools'`（旧代码 `isWeixinDevTools()`，`pages/broadcast/index.vue:276`） | **外围广播不可用**：P008 真机调试横幅 + 检查支持→不支持 + 启动拦截（对齐旧代码 checkWxBleSupport 失败路径）；扫描/GATT 域不受影响 |
| PC 端微信 | — | 【未知，未验证】旧代码未覆盖，不建模；待真机验证后回写本表 |

原型呈现：P009 应用信息卡「宿主系统」切换入口；P008 平台徽标注宿主（微信 · iOS 真机 / 安卓真机 / 开发者工具）。默认 iOS 真机（= 基准 mock env 口径）。

## 3. 优势 / 限制（10_platform §2.1）

- **优势**：微信生态分享直达（F029 右上角菜单）；零安装快速触达；扫码 / 授权引导链路成熟（F002/F020）。
- **限制**：后台即挂起（扫描/连接仅前台——现状 onUnload 停扫即为此设计）；peripheral 广播能力有限（wx.createBLEPeripheralServer，功率仅三档映射）；包体与类目审核。

## 4. 交互方式（平台表达）

| 交互 | 微信形态 |
|---|---|
| 设备发现 | 连续扫描列表（基准 P001） |
| 权限 | 微信授权弹窗 + 去设置（P001 六态权限分支，基准内置） |
| 扫码 | uni.scanCode（P002 配对码） |
| 分享 | 社交卡片 / 右上角菜单（客户端胶囊触发，不由页面绘制） |
| 外链 | 复制到剪贴板（toast 确认） |
| 推广卡（F028） | `navigateToMiniProgram` 直跳（基准行为不变，演示环境拦截提示）；落地页+小程序码承接仅用于非微信渠道（10_platform §4，2026-09-03） |
| 日志导出 | 剪贴板（F011 基准） |
| 生命周期 | 后台挂起即停扫/停广播（BR-06 的微信表达） |
