## 1. 审查方法与范围

- **结构分析**：三层模型（tab / 二级页 / 弹层）层级深度与职责判定。
- **移除影响**：PAGE004 摘除后的图结构变化（入度/出度、孤岛检测）。
- **命名与口径**：页面命名、跨页口径一致性（「已连接」计数等）。

## 2. 结论摘要

| 维度 | 结论 |
|---|---|
| 导航结构 | 三层模型健康：L0 tabBar ×4 / L1 二级页 ×5 / L2 弹层；最深 2 跳，无深栈风险 |
| PAGE004 移除影响 | P001 职责纯化（只做发现分流）；P003 变为会话级终点页（入度 2，均来自配网会话内）——无孤岛缺陷，语义变化由 P-02 文案承接 |
| 命名 | 文档层编号清晰；用户视角 P003/P006 双「设备详情」需 v1 标题区分（IA-01） |
| 口径 | 「已连接」计数差异为刻意设计并已自解释（保持）；P006 断开与 P007 列表内存同步 ✅ |
| 发现 | IA-01（B 类标题区分）为主项；IA-02/03 观察不动 |

## 3. 现状导航结构（移除 PAGE004 后）

```text
L0 tabBar（switchTab，互切无返回）
├── P001 扫描（默认页）
├── P007 已连接
├── P008 广播
└── P009 关于 ──→ L1 P010 版本记录
L1 二级页（navigateTo 入栈）
├── P002 配网向导 ←─ P001 SHID 卡 / P003 重新配置 / P005 重新配网
│   ├─成功→ redirectTo P003
│   └─错误恢复 diagnostics→ P005
├── P003 SHID 设备详情 ←─ P002 redirectTo / P005 栈感知
│   └─→ P002 / P005 / P006
├── P005 SHID 诊断 ←─ P003 / P002 恢复分流
│   └─→ P003 / P002（均栈感知）
└── P006 通用设备详情 ←─ P001 连接 / P007 点卡 / P003 高级调试
L2 弹层（页面内覆盖层）
└── 广播数据弹窗（P001）/ 写入弹窗、OTA 弹窗（P006）/ 各类确认 modal
```

**结构判定**：

- 层级深度：tab→L1 最深 2 跳；唯一的 L1→L1 跳转是 P002→P005（错误恢复），且 P005 出向用栈感知导航防叠加（PAGE_FLOW §1 注）——无栈失控风险。✅
- tabBar 四项与顺序（扫描/已连接/广播/关于）符合使用频次与工具主次：P001 默认页承载最高频 S1，P007 服务多设备调试回跳，P008 独立功能域，P009 低频收尾。✅ 保持。
- 全部页面入度 ≥1，无不可达页面（P003 的 2 个入度均来自配网会话内部，见 §4）。✅

## 4. PAGE004 移除后的架构影响

移除前：P001 是双枢纽（扫描面板 + 已配置面板→P004→P003 历史回访链）。
移除后（PAGE_FLOW §1 已更新口径）：

| 变化 | 判定 |
|---|---|
| P001 职责纯化为「发现与分流」，页面结构从 4 区块减为导航栏/工具条/面板/弹窗（PAGE_SPEC §1） | ✅ 正向：单一职责更清晰 |
| P003 入度收敛为 2（P002 成功 redirectTo / P005 栈感知返回），冷启动后无入口可达 | 非孤岛缺陷——入口收敛是决策结果；产品语义由「持久档案页」变为**会话级快照页**，v1 以 P-02 说明文案承接（详见 PRODUCT_REVIEW §5.2） |
| P004 摘除后无悬空跳转（原 P001「全部历史」入口已同步移除，QA 实测 0 死链） | ✅ 清理完整 |

## 5. 页面职责与命名

| 页面 | 职责一句话（现状口径） | 职责纯度 |
|---|---|---|
| P001 | 发现设备并分流（通用调试 / Profile 配网） | ✅ 移除面板后纯化 |
| P002 | 三步配网，全程可恢复 | ✅ |
| P003 | 本次配网会话的设备快照 + 三出口 | ✅（语义已变，见 §4） |
| P005 | 五项链路体检，指出坏在哪一环 | ✅ |
| P006 | 单设备 GATT 全功能调试台 | ✅ |
| P007 | 通用调试会话集中管理 | ✅ |
| P008 | 本机变外设，广播可定义可验证 | ✅ |
| P009/P010 | 产品/环境/版本透明化 | ✅ |

**双「设备详情」辨析**：P003「Smart HID 设备详情」vs P006「通用设备详情」。文档编号区分清晰，但用户视角两者标题文案相近而职责完全不同（配网快照 vs GATT 调试台）。现状各页导航栏标题文案【未知——逆向文档未单列各页标题文案，开发期可核对旧包】。

**IA-01（B 类，Phase 10）**：v1 原型将 P006 导航栏标题明确为「设备调试」或「GATT 调试」类文案，与 P003 形成用户可感知的区分（仅标题文案，不动路由与结构）。

## 6. 口径一致性

| 口径 | 现状 | 判定 |
|---|---|---|
| 「已连接」计数 | P001 工具条计数 = 通用连接 + SHID 配网会话；P007 列表仅通用会话（USER_FLOW S6 口径说明） | 刻意设计（避免配网会话占用调试列表），P007 双空态文案已自解释——保持（PRODUCT_REVIEW P-06） |
| 断开同步 | P006 断开 → P007 列表响应式同步（PAGE_FLOW §2） | ✅ 内存态无延迟 |
| 命名链 | tab「已连接」/ P001 计数「M 台已连接」/ P007 页面职责描述，三处同词同义 | ✅ |
| 广播状态词 | 徽章六值与 BROADCAST_STATE 对齐（QA §六 状态机） | ✅ |

## 8. 结论

信息架构在移除 PAGE004 后依然健康：三层模型、最浅可达性、栈感知防叠加、口径自解释均成立；唯一实质动作是 IA-01 的 v1 标题区分与承接 P003 语义变化的 P-02 文案。导航结构 v1 **不做结构性改动**。
