## 4. 工具性发现（测试方法登记）

本机（Samsung SM-G9910 + Flutter debug）`uiautomator dump` 存在**语义树冻结**：连续多份 dump 字节级雷同且与实况（logcat/空口/像素）矛盾。F-AND UI 状态判定应使用三路独立证据：① 像素采样（徽章色块等固定坐标特征）② flutter tag logcat（handler 链）③ Windows `BleAdvDump.exe` 空口锚点。后续轮次沿用。
