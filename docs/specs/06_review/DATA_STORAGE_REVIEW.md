## 1. 审查方法

按评审规范 §9 数据四分类（用户数据 / 配置数据 / 临时数据 / 日志数据）对本产品全部数据逐类判定**存储位置与生命周期**；F023 残留复查结论直接复用 PRODUCT_REVIEW §5（本轮不重复取证）。

## 2. 结论摘要

| 维度 | 结论 |
|---|---|
| 存储形态 | **零本地持久化**：无任何本地存储键、无 App 主动文件写入（原唯一键 `smart_ble.smart_hid.known_devices.v1` 及 90 天/20 条约束随 F023 移除，PRD 变更记录） |
| 数据分类 | 评审规范 §9 四类中，**用户数据 / 配置数据为空**；临时数据与日志数据全部为**会话内存态**，冷启动即空 |
| 敏感数据 | 配网 token 与 Wi-Fi 密码全链路仅内存（TTL 5 分钟）+ 日志脱敏黑名单双保险（R28 / F026） |
| 残留复查 | 5 处「落历史/落档/knownDevices」文档残留已于 Phase 8 修正（PRODUCT_REVIEW §5.1，P-01 ✅）；本轮无新增发现 |
| 平台一致性 | 「零本地持久化」为 L1 产品不变式（specs README 总纲；10_platform §4），全平台强制 |

## 3. 数据分类盘点（评审规范 §9）

| 类别 | 本产品对应数据 | 存储 | 生命周期 | 源 |
|---|---|---|---|---|
| 用户数据 | **无**（无账号体系、零登录，产品边界） | — | — | PRD §1.3 |
| 配置数据 | **无**（原「已配置设备档案」随 F023 / PAGE004 移除） | — | — | PRD 变更记录 |
| 临时数据 | 扫描结果（上限 100 台）、连接会话表、配网表单与 token（内存 TTL 5 分钟）、P003 会话快照、GATT 服务树、诊断结果、广播会话与 payload | 内存（store / 页面栈 / 会话注册表） | 冷启动即空；配网页 onUnload 清敏感数据并断连 | DATA_FLOW §1/§4/§6；PAGE_SPEC §0.4 |
| 日志数据 | core logger 环形缓冲（全局 500 条 / 单设备 200 条 / LRU 40 设备，脱敏后） | 内存 | 冷启动即空；「清空日志」手动清 | DATA_FLOW §7 |

补充：OTA 选包走 `wx.chooseMessageFile` 用户选择的临时文件，读入传输后 App 不保留（DATA_FLOW §5）；日志导出经剪贴板出站，不落盘（DATA_FLOW §7）。

## 4. 敏感数据处理（与权限/安全的交界）

- token 仅内存、TTL 5 分钟（STATE_MACHINE §3）；Wi-Fi 密码仅内存，离开配网页即清（PAGE_SPEC §0.4）。
- 日志侧 `SENSITIVE_PROFILE_KEYS` 黑名单脱敏 + 导出前脱敏（DATA_FLOW §7，对应 F026 / R28）。
- 配网表单底部隐私声明常驻：「Wi-Fi 密码和配对凭据只用于本次下发，不写入日志或本地存储」（PAGE_SPEC §2）。

## 5. 平台约束

零本地持久化对**所有平台**生效（L1 不变式）。平台文件系统能力（如 Desktop）只能服务于**用户主动的导出/导入**（10_platform §2.4 候选增强），App 自身不得自动落盘；此类增强已被平台扩展检查三查约束（10_platform §7）。
