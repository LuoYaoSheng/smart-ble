# 2. BLE-001 蓝牙环境检测

## BLE-001-01 检测BLE能力

判断设备是否支持 BLE。

返回：

``` json
{
  "support": true
}
```

## BLE-001-02 获取蓝牙状态

状态：

-   unknown
-   poweredOff
-   poweredOn
-   unauthorized

## BLE-001-03 权限检测

检测：

-   蓝牙权限
-   定位权限（Android）
-   附近设备权限

## BLE-001-04 引导开启蓝牙

跳转系统设置。

## BLE-001-05 获取平台信息

返回：

``` json
{
  "platform": "ios",
  "version": "18"
}
```
