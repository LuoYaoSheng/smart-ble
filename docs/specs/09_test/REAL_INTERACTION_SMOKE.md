# 真实交互烟测基线（REAL_INTERACTION_SMOKE）

- 状态：初版（Phase B 首轮，2026-09-04）
- 铁律：**必须真实点击 UI**——不得只调用场景库、不得直接注入最终状态；每项记录用户动作/前置条件/预期/实际/截图
- 适用：U-WX（Android 微信真机）、U-AND（Android App）、F-AND（Flutter Android）

## 1. F020 扫码（P002 入口）

| 用例 | 前置 | 动作 | 预期 |
|---|---|---|---|
| SMOKE-QR-001 | 权限未授 | 首次扫码触发相机权限弹窗→允许→扫有效码 | 解析成功进入下一步 |
| SMOKE-QR-002 | 已授权 | 扫码后取消 | 返回表单，无残留状态 |
| SMOKE-QR-003 | 已授权 | 相机权限在系统设置中拒绝后扫码 | 引导去系统设置（不静默失败） |
| SMOKE-QR-004 | 已授权 | 扫无效二维码 | 无效提示 + 可重试 |
| SMOKE-QR-005 | QR-004 后 | 重新扫有效码 | 恢复成功 |

## 2. P005 Smart HID 诊断

| 用例 | 动作 | 预期 |
|---|---|---|
| SMOKE-DIAG-001 | 设备在线时进入诊断 | 五项检测真实执行并出结果 |
| SMOKE-DIAG-002 | 设备离线时连接并诊断 | 连接失败→诊断失败态与恢复动作 |
| SMOKE-DIAG-003 | 注入诊断失败（断电/超时） | 失败态明确、错误分类正确 |
| SMOKE-DIAG-004 | 失败后恢复设备再检 | 重新检测恢复成功 |
| SMOKE-DIAG-005 | 快速连续触发两次检测 | 旧 operationId/generation 回调不污染新运行 |

## 3. P006 GATT 详情入口复用

|---|---|---|

## 4. 空态（真实首启/真实清空）

| 用例 | 场景 | 预期 |
|---|---|---|
| SMOKE-EMPTY-001 | P001 冷启动未扫描 | 未扫描空态（非错误态） |
| SMOKE-EMPTY-002 | P001 筛选无结果 | 空结果态 + 清筛选入口 |
| SMOKE-EMPTY-003 | P006 无服务 | 无服务态与重试 |

| SMOKE-EMPTY-006 | 设备无 action | 不渲染空按钮/空卡片动作区 |

## 5. 记录格式

每用例：run ID、commit、实现线、截图/录屏路径、结果（PASS/FAIL/BLOCKED）；FAIL 必须给第一断点（按 §23 定位链）。
