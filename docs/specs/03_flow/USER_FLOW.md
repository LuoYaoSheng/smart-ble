# USER_FLOW —— 用户旅程

> SOP v2.0 Phase 4 产出 · 2026-09-02
> 事实源：[../02_product/PRD.md](../02_product/PRD.md) §3 场景 / §7 流程 + [PAGE_SPEC.md](PAGE_SPEC.md)。S3 已按 2026-09-02 变更后入口描述。

## S1 调试自研 BLE 设备（U1 固件开发者 · 最高频）

```
打开小程序 → P001 点「开始扫描」
  →（权限前置 F002：微信蓝牙/定位授权）
  → 5s 扫描会话：节流合并、RSSI 降序（F001）
  → 点设备卡本体 → 广播数据弹窗，可复制（F004）
  → 普通卡「连接」→ P006（F006）
  → GATT 服务树浏览（F007）→ 读取 F008 / 写入 F009 / 监听 F010
  → 通信日志复制导出（F011）
  → 断开连接（P006 或 P007），会话移出已连接列表
```

**异常出口**：授权拒绝→错误横幅+去设置；蓝牙未开（10001）→引导开启；扫描失败→横幅重试；设备断电→被动断线自动重连 ×3（1s/3s/5s，F012）→仍失败则 FAILED，详情页手动重试；读写失败→日志「错误」（errCode 中文归一）。

## S2 Smart HID 设备首次配网（U2 硬件工程师）

```
P001 扫描 → SHID-XXXX 卡（UUID 强匹配 STRONG 徽章，F018）
  → 点「配置 Smart HID」→ P002 向导
  → phase=connect：自动连接 + 读 Device Info 身份验证（product/协议版本/deviceId 正则）
  → phase=configure：填 Wi-Fi SSID/密码 + ControlHub 地址
  → ControlHub 网页生成配对码 → 点「扫描配对码」扫码（F020，地址自动回填，token 仅内存 5 分钟）
  →「下发配置」→ candidate JSON 分帧明文写 INPUT（F021，各平台均不触发系统配对）
  → phase=status：四行进度（Wi-Fi→ControlHub→MQTT→控制链路）由 STATUS 推送驱动，60s 超时
  → state=ready 四行全绿 →「查看设备」redirectTo P003
```

**异常出口**：身份验证失败→断开+重连/返回；扫码取消/权限/失败→分类中文提示可重扫；8 种设备侧错误码→恢复动作分流（F022：form 回表单保留已填/pairing 重扫码/diagnostics 跳 P005/retry 重下发）；60s 超时→取消等待；配网中物理返回→确认弹窗；configure 阶段断线→表单保留+重连续传。

## S3 Smart HID 设备故障排查（U2/U3 · 2026-09-02 变更后入口）

```
让设备进入配网/恢复模式（READY 设备已关闭蓝牙广播——边界前提）
  → P001 扫描出 SHID 卡 →「配置」→ P002
  → 若配网报错 → 恢复按钮「运行诊断」→ P005
  →（或已连接成功后经 P003「运行诊断」→ P005）
  → P005 重新检测：未连接→确认「连接并检测」→ 连接 + 读取实时状态（F024）
  → 五项结论（BLE/Wi-Fi/ControlHub/控制连接/USB Ready）指出异常环
  → 展开错误码详情 → 按指引重新配网或回表单修改
```

**异常出口**：连接失败→modal 提示让设备进配网/恢复模式；诊断失败→toast；「返回设备详情/重新配网」为页面栈感知导航（栈中有则返回复用，不叠加实例）。

## S4 广播数据验证 / 教学（U3/U4）

```
切「广播」Tab → P008
  → 微信真机：从机模式建立（有活动连接则拦截提示先断开；开发者工具提示需真机）
  → Android App：系统蓝牙开闭检查 + 逐项权限引导 + 加载原生插件（F015）
  → 填设备名/服务 UUID/厂商 ID+数据（Android 另有模式/功率/可连接选项）
  → 字节数实时核算「N / 31 字节」（F016），超限红字阻止启动
  →「开始广播」→ 状态徽章「广播中」→ 用扫描端/LightBLE Observer 验证
  → 停止广播 / 离开页面自动停（非 APP），微信释放外围模式
```

**异常出口**：UUID 格式无效黄条；超 31B 阻止；插件未初始化；权限缺失清单+去设置；蓝牙未开引导；Web 平台明确不支持。

## S5 固件升级（U1 · 受限场景）

```
P006（设备含 OTA 服务 4fafc201-…-914d，「固件更新」可见）
  → 选 .bin（可选 manifest.json）→ 六重包校验（target/hardware/SemVer/sha256 实测）
  → 接管会话（期间禁自动重连）→ MTU 247 → start（chunk 180）
  → 分包传输（20ms 间隔）带进度 → commit → 重连回读固件版本比对
  → 一致才报成功，2s 自动关闭弹窗；任意时刻可取消（abort）
```

⚠ 当前产品状态：OTA 标注 **BLOCKED**（客户端与固件完整事务尚未对齐 E5），属受限开放能力。

## S6 多设备会话管理（U1/U3）

```
「已连接」Tab → P007 查看保持中的通用调试会话
  → 点卡 → 回到对应 P006 / Profile 路由
  → 单台「断开」/「全部断开」（allSettled；部分失败 modal 列失败清单，F013）
```

**口径说明**：Smart HID 配网会话不占用 P007 列表，但计入 P001「已连接」计数（避免口径漂移）。
