> 版本：1.0 · 生成日期 2026-09-02
> 输入：[PRD.md](../02_product/PRD.md)（编号体系一致：PAGE001-PAGE010、F001-F030）
> 性质：**只描述交互，不做视觉设计**。所有条目来自现有实现行为（逆向报告 §4 为事实源）。
> 备注：本产品**无网络请求**（零 HTTP），模板检查项「网络异常」在本产品映射为**蓝牙链路异常**（蓝牙未开/断线/外围模式失败），下文按此口径逐页标注。

# 0. 全局交互约定

## 0.1 导航约定
- TabBar 四项（扫描 PAGE001 / 已连接 PAGE007 / 广播 PAGE008 / 关于 PAGE009），switchTab 切换。
- 二级页一律 navigateTo 入栈；配网成功进详情用 **redirectTo**（替换向导页，防止返回回到已完成的向导）。
- **页面栈感知导航**（PAGE005 首创）：目标页已在栈中时 navigateBack 复用，避免叠加实例。
- 空态「去扫描」类按钮一律 switchTab 回首页。

## 0.2 反馈约定
- 轻反馈：uni.showToast（success 有图标 / none 纯文字）。
- 重反馈/确认：uni.showModal（危险操作「移除」「重新配网」「离开配网」均二次确认）。
- 复制类操作：uni.setClipboardData 成功后 toast（「已复制」「日志已复制」「网址已复制」「版本已复制」）。
- 无 loading 遮罩层；加载态一律内联（operation-state 组件 / 按钮文案变化 / 禁用）。

## 0.3 平台条件行为框架
- 广播页：微信（peripheral API）/ App（原生插件）/ 其他（不支持）三分支。
- 关于页外链：微信端复制到剪贴板（无法直接打开）；APP 端拉起浏览器；H5 新窗口。
- 分享：微信 onShareAppMessage/onShareTimeline；APP 系统分享（失败降级复制）；H5 navigator.share（失败降级复制）。
- 扫描权限前置仅在微信端做授权检查（services/scan-permission.js，唯一直调 wx.* 的服务）。

## 0.4 生命周期触发的隐式交互
- 首页 onHide/onUnload 自动停止扫描（原因 page_hide/page_unload）。
- 广播页 onHide：非 APP 平台自动停广播；微信端释放外围模式；onUnload 同。
- 配网向导 onUnload：清空密码/hubInfo 并断开连接（敏感数据不残留）。
- 诊断页 onUnload：若本页持有连接则断开。
- 通用详情 onUnload：解绑日志订阅/定时器/断连回调。

# 1. PAGE001 扫描首页

- **页面目标**：设备发现与分流（通用调试 / Profile 配网），兼管本机 Smart HID 历史。
- **进入条件**：App 启动默认页 / tabBar 切换 / 各页「去扫描」switchTab / 微信分享卡片落地。
- **页面结构**（自上而下）：①自绘导航栏（蓝牙状态）②扫描工具条 ③附近设备面板（筛选 + 列表）④广播数据弹窗（覆盖层）。（2026-09-02 决策：原「已配置 Smart HID」面板移除）
- **组件列表**：app-navbar / scan-summary（内嵌 error-banner）/ filter-panel / device-card（扫描态）/ empty-state / advertisement-dialog。
- **按钮列表与行为**：

| 按钮 | 出现条件 | 行为 |
|---|---|---|
| 开始扫描 ⇄ 停止扫描 | 始终（工具条主按钮） | 开始：权限前置检查→启动 5s 扫描会话，按钮变 danger「停止扫描」；停止：立即中止（reason=user）。扫描完成（超时自动停）toast「扫描完成 · 发现 N 台」 |
| 重试 | 仅错误横幅显示时 | 重新走 startScan 流程 |
| 筛选 ⇄ 收起筛选 | 始终（文字链） | 展开/收起 filter-panel |
| RSSI 预设 ×4 / 滑杆 / 名称前缀输入 / 隐藏无名开关 / 重置过滤 | 筛选展开时 | 实时作用于列表（无确认按钮）；重置回 {rssi:-100, prefix:'', hideNoName:false} |
| 全部历史 / 已知设备查看 / 移除 | ~~已配置面板~~ | 【已移除 2026-09-02 用户决策】首页不再呈现已配网设备管理 |
| 连接 | 普通设备卡 | 等扫描收尾（prepareConnect）→ 暂存路由上下文 → navigateTo PAGE006（携带 deviceId/name/rssi） |
| 配置 Smart HID | SHID 设备卡（Profile 匹配） | 等扫描收尾 → setCurrentDevice → navigateTo PAGE002 |
| 复制数据 / 关闭 | 广播数据弹窗内 | 复制报告全文 toast「已复制」/ 关闭弹窗 |
| （点设备卡本体） | 任意设备卡 | 打开广播数据弹窗（与「连接」按钮互不干扰） |

- **状态列表**：
  - 蓝牙：就绪（绿点）/ 未开启 / 平台不支持（导航栏三态文案）。
  - 扫描：待开始 / 扫描中 / 需重试（失败）/ 已完成（工具条标签）。
  - 列表：无结果空态 / 有结果但被筛选清空（两种空文案）/ 正常列表。
  - 设备卡：普通 / SHID（徽章+双按钮）/ 已连接（「连接」按钮变「已连接」disabled）。
- **跳转关系**：→PAGE006（普通连接）/ →PAGE002（SHID 配置）。（原 →PAGE003 已知设备查看 / →PAGE004 全部历史 已随 2026-09-02 决策移除）
- **异常处理**：
  - *空状态*：无扫描结果→「还没有扫描结果/点上方按钮开始扫描」；筛选无匹配→「当前没有匹配设备/调整筛选试试」。
  - *加载状态*：扫描中由工具条标签+按钮态表达，列表增量刷新（1s 节流）。
  - *错误状态*：扫描失败→横幅（标题含 error.code）+重试。
  - *权限状态*：微信授权拒绝→横幅 reason 分类（bluetooth_permission_denied 等）+引导设置；蓝牙未开（10001）→弹「请先打开系统蓝牙」。
  - *蓝牙链路*：适配器初始化失败自动指数退避重试 3 次（1s/2s/4s）后仍失败才报错。
  - *用户取消*：无 destructive 取消场景（停止扫描即按钮）。
- **数据展示规则**：设备显示名按多级 fallback（name→localName→AD 0x09→AD 0x08→Profile 名→厂商→「未命名 BLE · ID后四位」）；RSSI 四格信号条（-60/-70/-80 分档）+ dBm 数值；deviceId 等宽字体截断；已连接计数 = 通用连接数 + SHID 配网会话在线（+1）；广播数据弹窗中平台未提供字段标注「本轮平台 API 未提供此字段」，长度 0 标注「字段存在但长度为 0」。

# 2. PAGE002 Smart HID 配网向导

- **页面目标**：三步完成配网（连接→填写→状态），全程可恢复。
- **进入条件**：PAGE001 SHID 卡「配置」（携带设备）/ PAGE003「重新配置」（currentDevice 已设）/ PAGE005「重新配网」（经确认弹窗）。
- **页面结构**：①三步骤条（常驻）②阶段面板（三选一渲染）：connect 阶段 / configure 阶段 / status 阶段。
- **组件列表**：provision-stepper / provision-progress / operation-state。
- **按钮与输入列表与行为**：

| 元素 | 出现条件 | 行为 |
|---|---|---|
| Wi-Fi 名称输入（≤32 字符） | configure 阶段 | 实时双向绑定，无提交即校验 |
| Wi-Fi 密码输入（≤64，password 型） | configure 阶段 | 可留空（placeholder「无密码可留空」） |
| ControlHub 地址输入 | configure 阶段 | placeholder 192.168.1.8:17892；扫码后自动回填 host:port |
| 扫描 ControlHub 配对码（大动作卡） | configure 阶段 | 调起扫码→解析 shid://pair→回填地址+token 入内存（badge 必需→已获取，标题变「重新扫描…」）；失败按取消/权限/失败分类提示 |
| 下发配置 | configure 阶段 | canSubmit（SSID+Hub+token 齐且非配网中）才可点；点击后进入 status 阶段 |
| 取消等待 | status 阶段·配网进行中 | 取消 60s 等待，回到可重试状态 |
| 查看设备 | status 阶段·配网成功 | redirectTo PAGE003（保留会话） |
| 恢复按钮（文案随错误变） | status 阶段·失败 | 四种动作：回表单 form / 重新扫码 pairing / 跳诊断 diagnostics / 重下发 retry |
| 重新连接 / 返回设备列表 | connect 阶段·连接失败 | 重连本设备 / switchTab 回首页 |
| 重新连接设备 | configure 阶段·断线 | 重连后已填表单保留继续 |
| （物理返回键） | 配网进行中 | 拦截→确认弹窗「离开将取消本次配置等待」→允许才 navigateBack |

- **状态列表**：phase（connect/configure/status）；connecting；connectionError；connectionLost（徽章 已连接⇄已断开）；pairingReady（badge）；provisioning（进行中）；provisionDone；errorMessage+recoveryAction；四行进度各行 pending/active/done/fail/warn。
- **跳转关系**：→PAGE003（成功 redirectTo）/ →PAGE005（recovery=diagnostics）/ 返回首页（返回设备列表、失败兜底）。
- **异常处理**：
  - *加载状态*：connect 阶段「连接并确认设备中…」；status 阶段四行进度实时推进即过程反馈。
  - *错误状态*：身份验证失败（非 smart-hid/协议版本/deviceId 格式）→错误态+重新连接；设备侧 8 错误码→定位失败行+中文提示+恢复按钮；60s 超时→取消等待。
  - *空状态*：无（进入即有设备上下文）。
  - *权限状态*：扫码权限拒绝→分类提示可重扫。
  - *蓝牙链路*：configure 阶段断线→徽章变红+说明「已填写的配网信息不会丢失」+重连按钮；Android 加密写首次触发系统配对弹窗→自动 2s 重试一次。
  - *用户取消*：物理返回确认；取消等待；扫码取消（分类提示，不算错误）。
- **数据展示规则**：设备摘要行展示 Device Info 解析结果（等宽字体）；隐私声明常驻表单底部（「Wi-Fi 密码和配对凭据只用于本次下发，不写入日志或本地存储」）；进度行文案固定四项（Wi-Fi/ControlHub/MQTT 控制链路/USB Ready）；成功态说明「HID 控制请通过 ControlHub 下发」（引导用户离开）。

# 5. PAGE005 Smart HID 诊断

- **页面目标**：五项链路体检（BLE/Wi-Fi/ControlHub/控制连接/设备 Ready），指出坏在哪一环。
- **进入条件**：PAGE003「运行诊断」/ PAGE002 失败恢复（recovery=diagnostics）。携带 deviceId；优先从 currentDevice 与内存连接会话命中并 setCurrentDevice（2026-09-02 决策后无 knownDevices 本地记录）。
- **页面结构**：①当前状态行 ②五项诊断行列表 ③操作区（四按钮）④错误详情块（条件显示）。
- **组件列表**：无外部组件（自绘行）。
- **按钮列表与行为**：

| 按钮 | 出现条件 | 行为 |
|---|---|---|
| 重新检测（连接中…禁用） | 始终 | 会话不在线→offline 态+modal「BLE 未连接」（确认「连接并检测」→connect+diagnose；取消留在原地）；在线→直接 diagnose |
| 显示错误码（详细信息）⇄ 隐藏错误码 | 始终 | 切换错误详情块（code+message）显隐 |
| 返回设备详情 | 始终 | **页面栈感知**：栈中有 PAGE003 则 navigateBack，否则 navigateTo PAGE003 |
| 重新配网 | 始终 | modal 确认（READY 设备需先进配网模式，确认文案「已进入配网模式」）→栈中有 PAGE002 则返回，否则 navigateTo PAGE002 |

- **状态列表**：页面态六值（尚未检测/设备已连接可开始检测/正在读取实时状态/实时检测完成/设备未连接/检测失败）；每行五态（待检测 pending/检测中 active/正常 ok/异常 warn/失败 fail）。
- **跳转关系**：→PAGE003（栈感知）/ →PAGE002（栈感知）。
- **异常处理**：
  - *加载状态*：connecting→按钮「连接中…」禁用；checking 态文案。
  - *错误状态*：连接失败→error 态+lastError 记录+modal「请让设备进入配网/恢复模式后重试」；诊断失败 toast。
  - *空状态*：无诊断数据时显示五行 pending 待检测（不是空白）。
  - *蓝牙链路*：offline 态处理见「重新检测」。
  - *用户取消*：连接确认 modal 取消→停留；重新配网确认取消→停留。
- **数据展示规则**：状态行图标 ✓/!/…/· 与状态词（正常/异常/检测中/待检测/失败）一一对应；每行可展开 detail 明细文字；错误码块 code 等宽字体；诊断结果由设备 status.state/step/error 映射（错误串定位异常行）。

# 6. PAGE006 通用设备详情（GATT 调试工作台）

- **页面目标**：单设备 GATT 全功能调试台（读/写/监听/日志/OTA）。
- **进入条件**：PAGE001 普通卡「连接」（URL 携带 deviceId/name/rssi[/profileId] 或暂存上下文）/ PAGE007 点卡 / PAGE003「高级 BLE 调试」。路由参数无效→modal 后返回。
- **页面结构**：①设备面板（头部+操作行）②服务树滚动区 ③日志面板（dock 底部）④写入弹窗 ⑤OTA 弹窗（均覆盖层）。
- **组件列表**：service-panel（内用 operation-state）/ log-panel / write-dialog / ota-dialog。
- **按钮与热区列表与行为**：

| 按钮 | 出现条件 | 行为 |
|---|---|---|
| 固件更新（danger） | 仅检测到 OTA 服务（4fafc201-…-914d） | 打开 ota-dialog |
| 清空日志 | 始终 | 清空本会话日志列表 |
| 导出日志 | 始终 | 有日志→格式化文本复制+toast「日志已复制」；无日志→toast「暂无日志」 |
| 连接设备 ⇄ 断开连接 | 始终 | 初始化/连接中显示「连接中…」禁用；已连接变 danger「断开连接」（主动断开，不触发重连）；未连接点击走连接流（复用会话→10s 超时→自动重试 3 次退避 n×2s） |
| 重试 | 服务面板 error 态 | 手动重连（manualRetryConnection） |
| 全部展开 / 全部收起 | 服务树 ready 态 | 批量折叠切换 |
| （服务折叠头） | 每服务 | 单服务展开/收起 |
| 读取 | 特征 properties.read | 发起读（3s 超时）→日志「接收」HEX+TEXT；失败日志「错误」 |
| 写入 | 特征 properties.write | 记录目标特征→打开 write-dialog |
| 开始监听 ⇄ 停止监听 | 特征 properties.notify | 开→订阅+char.notifying 同步+日志「系统」；关→取消订阅；防抖去重 |
| （write-dialog）数据类型单选 TEXT/HEX + 数据输入 + 确认/取消 | 弹窗打开时 | 确认：空输入 toast「请输入数据」；HEX 非法拦截；合法→写队列串行下发→toast「写入成功」+日志「写入」；失败日志「错误」 |
| （ota-dialog）选择文件 / 取消 / 关闭 | 弹窗打开时 | 选 .bin（微信 chooseMessageFile）→校验→传输进度→成功 2s 自动关闭；取消→abort |

- **状态列表**：isInitializing / isConnecting / isConnected（状态点灰⇄绿）；服务面板五态 idle/connecting/ready/empty/error；isSending（写弹窗）；OTA 12 态（VALIDATING/SUBSCRIBING/STARTING/READY/TRANSFERRING/COMMITTING/VERIFYING/SUCCESS/FAILED/CANCELLED…）；被动断线→自动重连（3 次 1s/3s/5s），重连期间日志反馈。
- **跳转关系**：无出向 navigateTo（返回即 navigateBack）；断开后可返回 PAGE001/PAGE007 复用。
- **异常处理**：
  - *空状态*：服务发现完成但为空→面板 empty 态（专用文案）。
  - *加载状态*：connecting 面板态+按钮禁用；OTA 进度条。
  - *错误状态*：连接失败→error 面板+重试；读/写/监听失败→日志「错误」行（errMsg 中文归一化，微信 10000-10013 映射）。
  - *权限状态*：蓝牙未开→初始化错误文案引导。
  - *蓝牙链路*：被动断线→写队列 abort（未发事务取消不重发）→自动重连；手动重试上限 3 次。
  - *用户取消*：写弹窗取消；OTA 取消（发 abort 给设备）。
- **数据展示规则**：服务/特征优先显示标准中文名（SIG UUID 映射表），未知显示「服务 N/特征值 N」；接收数据固定双格式「HEX: 大写空格分隔 + TEXT: UTF-8 解码（失败省略）」；日志条目=时间+类型 chip（六色 sys/err/read/write/recv/ok）+消息；日志导出为格式化纯文本；OTA 进度按阶段切换文案（确认设备/传输中 N%）。

# 8. PAGE008 BLE 广播

- **页面目标**：本机变 BLE 外设发射可定义广播，31 字节预算可视。
- **进入条件**：tabBar「广播」/ 微信分享卡片。进入即自动检查支持（微信 onShow 也查）。
- **页面结构**：①设置卡（头部状态区+表单区+字节提示+操作区）②操作日志面板（card 变体）。
- **组件列表**：log-panel。
- **输入与按钮列表及行为**：

| 元素 | 出现条件 | 行为 |
|---|---|---|
| 设备名称输入 | 始终（广播中禁用；Android 提示用系统蓝牙名） | 实时参与字节预算 |
| 服务 UUID 输入 | 始终（广播中禁用） | 4/8/36 位 hex 校验，非法显示黄条错误 |
| 广播模式 picker（低功耗/平衡/低延迟） | 仅 Android | 默认「平衡」 |
| 发射功率 picker（超低/低/中/高） | 仅 Android（微信端映射 low/medium/high） | 默认「高功率」 |
| 可连接 / 包含设备名称 / 添加服务 UUID 开关 ×3 | 仅 Android | 实时影响 payload 构成与预算 |
| 厂商 ID（HEX）/ 厂商数据输入 | 始终（广播中禁用） | 1-4 位 hex；参与预算（厂商块 2+2+len） |
| 开始广播 ⇄ 停止广播（主按钮） | 始终 | 开始：payload 校验（超限/字段非法 toast 阻止）→平台分支（Android：蓝牙开闭检查+权限引导→插件；iOS：插件；微信：peripheral+server 链路；Web：toast 不支持）→成功状态徽章「广播中」按钮变 danger；停止：停播（微信关 server） |
| 检查支持 | 始终 | 平台分支探测（App 插件 isSupported / 微信建立从机链路 / 其他标记不支持），结果写入日志与徽章 |

- **状态列表**：平台标签（Android/iOS/微信/Web）；运行徽章六值（广播中/失败/已停止/已就绪/未就绪/不支持）；广播中全部输入禁用；字节提示（N/31 + 超限红字）；页面态 Idle/Advertising/Error/Stopped。
- **跳转关系**：无出向跳转（tab 页）。
- **异常处理**：
  - *空状态*：日志空态「暂无日志/开始广播或检查支持后…」。
  - *加载状态*：无显式 loading（启停为快异步，结果经徽章与日志反馈）。
  - *错误状态*：UUID 非法黄条；超 31 字节红字+阻止启动；启停失败→徽章「失败」+错误日志+toast。
  - *权限状态*：Android 逐项请求权限（FINE_LOCATION；SDK≥31 加 ADVERTISE/CONNECT），缺权限 modal「去设置」跳应用详情；系统蓝牙关闭→modal 引导开启（Intent）。
  - *蓝牙链路*：微信外围模式建立失败→错误日志（errMsg 详情）；有活动 BLE 连接→报 active_connections 提示先断开；微信 errCode 10001→「请先开启系统蓝牙」；开发者工具→提示需真机调试。
  - *用户取消*：权限弹窗拒绝→汇总缺失清单+去设置；系统蓝牙引导取消→停留。
- **数据展示规则**：字节预算实时计算展示（AD 结构逐项：名称 2+len、UUID、厂商块 2+2+len），**超限显示但不静默截断**；默认值预填（微信：SmartBLE/FFE0/0001/BLE；Android：SmartBLE-A；iOS：SmartBLE-I）；操作日志记录启停与支持检查（类型六色），进入页面回放历史（core logger 'broadcast' 命名空间）。
