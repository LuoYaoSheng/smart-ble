## 2. 平台无关性说明（规范 v2.0 §3）

本文不描述任何平台的按钮位置、导航或布局；规则的**执行方式**允许平台差异（如 BR-06 在微信为后台挂起、在 Web 为页签可见性守则、在 Desktop 为退出确认——同一规则的平台表达，见 `prototype/platform/{平台}/PLATFORM_SPEC.md`）。
