## 4. 复用关系（架构含义）

- Profile 配网域**复用** GATT 调试域的连接/写入/notify 基础设施（provisioning transport 构建在 ble-runtime 之上）。
- Profile 配网域经**注册表**给设备发现域注入识别能力（matchScannedDevices 贴徽章与专属动作）。
- 系统信息域（日志/脱敏/版本）横切所有域。
