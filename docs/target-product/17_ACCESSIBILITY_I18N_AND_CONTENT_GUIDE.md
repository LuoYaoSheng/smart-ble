## 2. 无障碍（A11y）目标

| 项 | 目标 | 验证 |
|---|---|---|
| 触控目标 | ≥44×44px；间距 ≥8px | E4 走查 |
| 对比度 | 正文 ≥4.5:1；大字 ≥3:1；亮暗两套主题都满足 | 工具+E4 |
| 读屏 label | 全部可交互元素有可读标签（中文）；状态芯片朗读"状态+含义" | E4（App/微信读屏抽测） |
| 焦点 | 键盘（Web）/遥控（TV N/A）顺序=视觉顺序；弹窗焦点圈定 | E4/E6 |
| 动态状态 | 状态变化有文字同步（不只颜色）：扫描中/广播中/诊断 pending | E4 |
| 错误文案 | 错误必含：发生了什么+下一步动作 | E4 |
| 图片 | 全部 img 有 alt（截图描述内容非装饰词） | E6 |
| 动效 | 尊重系统减动效设置 | E4 |
| 不只靠颜色 | ok/fail/pending、预算超限、连接状态全部图标+文字+颜色三通道 | E4 |

## 4. 文案规范

1. 语言：简体中文唯一（首版）；协议字段/错误码保留英文原文并附中文释义；
2. 句式：错误="无法 X：原因。下一步 Y。"；成功=结果+去向；按钮=动词短语；
3. 禁用词：稳定（无健康指标）、完整支持（无 E5）、稍后/以后再说（逃避动作）、"待定/占位"类空洞词；
4. 数字：阿拉伯数字；单位带空格（31 字节、5s）；
5. 品牌名统一：产品名"Smart BLE"，小程序名"BLE Toolkit+"；禁止旧名混用（SmartBLE Mini/LightBLE App 等仅可用于固件历史叙述）；
6. 平台措辞差异：微信内称"小程序"，App 内称"应用"；分享文案按平台定制但信息一致。

## 6. i18n 策略

首版仅简体中文；文案集中管理（页面级常量或资源文件），为后续多语言预留结构但不实现（Not Now）。协议/错误码一律英文原值+中文释义，保证与外部正典可对照。

## 7. 验收条件与关联测试规划

- A11y 目标可验证；
- 术语与文案规范覆盖禁用词与品牌统一；
- 状态文案有稳定 ID 模板。

关联计划测试：`TEST-P-001..010`（四态与文案）、`TEST-R-010`（Web a11y/对比度/alt）、`TEST-C-003`（禁用词扫描）。
