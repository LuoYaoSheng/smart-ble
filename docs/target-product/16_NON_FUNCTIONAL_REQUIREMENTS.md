## 1. 本文负责什么 / 不负责什么

本文负责：可量化的性能、稳定性、容量、兼容、恢复、可维护性目标与测试方法（NFR-001~024）。

本文不负责：功能行为（`03`）；安全（`15`）。

---

| ID | 指标 | 目标值 |
|---|---|---|

### 2.5 恢复

恢复目标内嵌于错误登记（`07` 每项恢复动作）与 OTA/配网事务（STATE-OTA/STATE-HID）；补充：应用被系统杀死后重启，本地数据完整、无半开会话残留（Registry 冷启动为空）。

## 3. 测试方法说明

- E1：纯函数计时/容量（Jest 级）；
- E2：Fake Runtime 注入（超时/迟到/并发）；
- E4：页面性能（渲染计时）；
- E5：真机（录屏+设备侧对照）；
- E6：Lighthouse/链接/下载工具。
