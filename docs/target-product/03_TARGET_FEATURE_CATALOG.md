## 1. 本文负责什么 / 不负责什么

## 2. SYS 平台与能力

#### FEAT-001｜启动与平台识别
- 归属：REQ-001｜PAGE-001｜FLOW-001｜优先级 Must
- 价值：用户冷启动即进入扫描 Tab，并从第一屏知道当前平台能做什么，不会在 H5 上碰到假 BLE。
- 前置：应用已安装/小程序已授权进入。输入：运行环境（Android App/微信/H5/iOS）。
- 输出：默认 Tab=扫描；平台能力结论（驱动后续降级）。正常：≤2s 内可交互（NFR-001）。
- 错误恢复：环境识别失败按最保守能力处理并提示 ERR-SYS-01。
- 平台差异：微信多一步基础库/权限策略；H5 直接 UNSUPPORTED 面。数据来源：运行时 API 探测。
- 依赖：无。安全隐私：无。
- 性能：冷启动到可交互 ≤2s。测试：TEST-U-001、TEST-P-001、TEST-A-001、TEST-W-001｜E4（App E5）｜发布条件：E5 通过且 PAGE-001 状态区展示正确。

#### FEAT-002｜四 Tab 与二级页导航
- 归属：REQ-002｜PAGE-001/007/008/009 + 二级页｜FLOW-001/006｜Must
- 价值：固定信息架构让用户形成肌肉记忆；URL 只传稳定身份字段避免敏感泄漏。
- 前置：FEAT-001。输入：用户点击/代码跳转。输出：路由切换 + 页面栈行为。
- 正常：Tab 切换保留状态；二级页返回回到来源页且设备上下文不丢。
- 错误恢复：非法参数（缺 deviceId）目标页弹说明并返回（ERR-SYS-02）。
- 平台差异：微信 TabBar 与 App 原生 Tab 实现不同但语义一致。数据来源：路由表（`05`）。
- 依赖：无。安全隐私：URL 禁止携带密码/token/完整广播（SEC-004）。
- 性能：页面切换 ≤500ms（NFR-002）。测试：TEST-C-005（路由契约）、TEST-P-001..010、TEST-A-002、TEST-W-002｜E4｜发布条件：路由与 `05` 完全一致。

#### FEAT-003｜应用前后台生命周期
- 归属：REQ-003｜PAGE-001/002/006/008｜FLOW-001/006｜Must
- 价值：切后台/锁屏不偷偷耗电、不丢会话；回前台状态正确刷新。
- 前置：任一页面活动。输入：hide/show/unload 事件。输出：扫描停止（PAGE-001）、页面资源释放；应用级 Session 按 DEC-009 保留。
- 正常：hide 停扫描；show 恢复状态展示；unload 清页面级 Listener/Timer。
- 错误恢复：恢复时检测蓝牙/权限状态变化并重算（ERR-PERM-01/ERR-BT-01）。
- 平台差异：微信 hide 限制更严格（不承诺后台 BLE 保持，`08`）。数据来源：生命周期事件。
- 依赖：无。安全隐私：无。
- 性能：无卡顿回归（NFR-020）。测试：TEST-I-001、TEST-A-003、TEST-W-003｜E2（App E5）｜发布条件：生命周期矩阵测试通过。

#### FEAT-004｜版本与构建渠道
- 归属：REQ-004｜PAGE-009/010、WEB-001｜FLOW-012｜Must
- 价值：版本五处一致，用户和贡献者都能对上"我装的是哪个 commit"。
- 前置：构建流程读取 VERSION。输入：VERSION 文件 + git shortsha。
- 输出：关于页/版本页/Release Metadata/落地页统一版本；开发版显示 `dev.<shortsha>`。
- 正常：首项版本记录 = 运行版本。错误恢复：VERSION 读取失败显示 `dev.unknown` 并记 ERR-DATA-05。
- 平台差异：微信版本受平台审核；本地显示仍以 VERSION 投影为准。数据来源：DATA-008。
- 依赖：无。安全隐私：无。
- 性能：无。测试：TEST-C-006、TEST-U-002、TEST-R-002｜E0+R｜发布条件：五处一致校验通过（`18`）。

## 3. PERM 权限

#### FEAT-005｜蓝牙权限请求与状态展示
- 归属：REQ-005｜PAGE-001｜FLOW-001｜Must
- 价值：权限是 BLE 第一道门；状态可见、可重试，用户不被"没反应"困住。
- 前置：FEAT-001。输入：系统权限 API。输出：状态区权限芯片 + 请求时机（首次扫描前）。
- 正常：授权后可扫描。错误恢复：拒绝→提示 + 重试入口（ERR-PERM-01）。
- 平台差异：Android 12+ BLUETOOTH_SCAN/CONNECT；微信走自身授权体系。数据来源：平台权限 API。
- 依赖：无。安全隐私：仅申请必需权限（SEC-001）。
- 性能：无。测试：TEST-U-003、TEST-P-001、TEST-A-001、TEST-W-001｜E4（真机 E5）｜发布条件：两平台权限链路 E5 通过。

#### FEAT-006｜微信 BLE 权限能力驱动最小申请
- 归属：REQ-006｜PAGE-001（微信）｜FLOW-001｜Must（原则见 DEC-003）
- 价值：按当前运行环境实际要求申请最小权限；不预取定位，避免权限滥用与"扫不到设备"死局。
- 前置：微信环境。输入：用户点击"开始扫描"；Capability Detection（微信版本/基础库/Android 组合）。输出：最小权限申请流程；仅当环境明确要求定位授权时才出现定位引导（ERR-PERM-02）；环境要求位置服务开启而未开时引导开启（ERR-PERM-04）；不需要定位的环境不出现任何定位 UI。
- 正常：授权→扫描可用。错误恢复：环境要求定位被拒→引导（ERR-PERM-02）；各组合真实要求由 TP-G4 真机矩阵回填（DEC-003 第 6 条）。
- 平台差异：仅微信；不同微信版本/基础库/Android 系统组合结论不同，禁止写死单一结论。数据来源：微信 API + 能力检测。
- 依赖：无。安全隐私：仅申请必需权限；定位仅在环境要求时申请且仅用于 BLE 扫描声明（SEC-001）。
- 性能：无。测试：TEST-W-001、TEST-W-004｜E5（微信）｜发布条件：DEC-003 真机矩阵关键组合验证通过。

#### FEAT-007｜永久拒绝恢复
- 归属：REQ-007｜PAGE-001｜FLOW-001 错误路径｜Must
- 价值：永久拒绝后普通请求不再弹窗，必须给系统设置出口。
- 前置：FEAT-005。输入：权限拒绝状态。输出：跳转系统设置（App）/小程序设置页（微信）。
- 正常：用户开启后返回 App 恢复。错误恢复：仍拒绝→保持 ERR-PERM-03 与说明。
- 平台差异：两平台入口 API 不同。数据来源：权限 API。
- 依赖：无。安全隐私：无。
- 性能：无。测试：TEST-U-003、TEST-A-001、TEST-W-001｜E5｜发布条件：双平台永久拒绝路径 E5 通过。

#### FEAT-008｜蓝牙关闭与系统设置引导
- 归属：REQ-008｜PAGE-001/008｜FLOW-001｜Must
- 价值：蓝牙关闭是最常见故障；一键引导开启。
- 前置：FEAT-001。输入：适配器状态回调。输出：蓝牙状态芯片 + "去开启"。
- 正常：开启后状态自动恢复（适配器状态监听）。错误恢复：ERR-BT-01；打开失败重试上限后提示。
- 平台差异：微信 10001 错误码语义。数据来源：适配器状态事件。
- 依赖：无。安全隐私：无。
- 性能：状态变化到 UI 更新 ≤1s（NFR-003）。测试：TEST-U-004、TEST-P-001、TEST-A-004、TEST-W-005｜E5｜发布条件：蓝牙开/关往返 E5 通过。

#### FEAT-009｜平台不支持降级
- 归属：REQ-009｜PAGE-001/008（H5/iOS 未发布）｜FLOW-001｜Must
- 价值：不模拟成功是信任底线。
- 前置：FEAT-001。输入：能力探测结果。输出：UNSUPPORTED 说明面 + 替代入口（去微信/App）。
- 正常：H5 展示文档与入口。错误恢复：无假交互；插件缺失检测（ERR-BT-03）。
- 平台差异：本特性即平台差异本身。数据来源：能力探测。
- 依赖：无。安全隐私：无。
- 性能：无。测试：TEST-P-001、TEST-W-006、TEST-R-003｜E4｜发布条件：H5 面不可触发任何真实 BLE API。

## 4. SCAN 扫描

#### FEAT-010｜扫描开始/停止/超时
- 归属：REQ-010｜PAGE-001｜FLOW-002｜Must
- 价值：可控扫描轮次，避免常驻扫描耗电。
- 前置：权限与蓝牙就绪。输入：开始/停止点击；默认时长（DEC-013：10 秒，可配置常量；可手动停止、完成后可立即重扫）。
- 输出：设备列表增量更新（1s 合并刷新，NFR-004）；停止后保留结果。
- 正常：一轮扫描完成自动停。错误恢复：启动失败→ERR-SCAN-01 横幅 + 重试；停止失败→兜底静默清理并记日志。
- 平台差异：微信重复发现需 allowDuplicatesKey 处理 RSSI 更新。数据来源：平台发现回调（经 Runtime 归一）。
- 依赖：无。安全隐私：无。
- 性能：见 NFR-004/005。测试：TEST-I-002、TEST-P-001、TEST-A-005、TEST-W-007、TEST-E-001｜E2→E5｜发布条件：双平台扫描 E5 + Observer 观测到广播。

#### FEAT-011｜第二轮独立扫描 generation
- 归属：REQ-011｜PAGE-001｜FLOW-002｜Must
- 价值：两轮扫描结果互不污染，迟到事件不复活旧数据。
- 前置：FEAT-010。输入：再次开始扫描。输出：新 generation；列表按策略重置后重建。
- 正常：旧 generation 回调被丢弃。错误恢复：无。
- 平台差异：无。数据来源：Scan Session 控制器。
- 依赖：无。安全隐私：无。
- 性能：无额外开销。测试：TEST-U-005、TEST-I-002｜E1/E2｜发布条件：随 FEAT-010。

#### FEAT-012｜deviceId 去重与 RSSI 更新
- 归属：REQ-012｜PAGE-001｜FLOW-002｜Must
- 价值：列表一设备一条，信号强度实时变化可见。
- 前置：FEAT-010。输入：发现事件流。输出：同 deviceId 合并、RSSI 覆盖更新。
- 正常：上限 100 条（NFR-006），超限停止新增并提示。错误恢复：无。
- 平台差异：deviceId 语义（iOS UUID vs Android MAC）由 Runtime 归一。数据来源：发现回调。
- 依赖：无。安全隐私：MAC 不上送任何远端（SEC-002）。
- 性能：列表操作 O(id)。测试：TEST-U-005、TEST-I-002、TEST-A-005、TEST-W-007｜E1→E5｜发布条件：随 FEAT-010。

#### FEAT-013｜设备显示名解析链
- 归属：REQ-013｜PAGE-001｜FLOW-002｜Must
- 价值：有广播名的设备不再显示"未知设备"；学习者也看得懂名称来源。
- 前置：FEAT-012。输入：name/localName/AD 0x09/0x08/Profile 厂商名。
- 输出：显示名按链解析；广播详情标注每段来源。
- 正常：`name→localName→AD 0x09→AD 0x08→Profile 厂商→未命名 BLE·ID后缀`；空名称不得覆盖已获有效名称。
- 错误恢复：全链缺失→兜底名（ERR 不是错误态，属显示规则）。
- 平台差异：微信字段完整性可能不同，解析链相同。数据来源：广播数据。
- 依赖：无。安全隐私：无。
- 性能：解析为纯函数。测试：TEST-U-006、TEST-A-005、TEST-W-007｜E1→E5｜发布条件：夹具广播名 `BLEToolkit-Server` 正确显示。

#### FEAT-014｜列表上限与筛选
- 归属：REQ-014｜PAGE-001｜FLOW-002｜Must
- 价值：嘈杂射频环境下快速定位目标设备。
- 前置：FEAT-012。输入：RSSI 阈值/名称前缀/隐藏无名开关。
- 输出：筛选后子列表；不影响底层数据。正常：筛选即时生效。
- 错误恢复：筛选无结果独立空态（STATE-P001-07）。
- 平台差异：无。数据来源：设备集合（纯函数过滤）。
- 依赖：无。安全隐私：无。
- 性能：过滤 ≤50ms（NFR-007）。测试：TEST-U-007、TEST-P-001、TEST-A-005、TEST-W-007｜E1→E5｜发布条件：随 FEAT-010。

#### FEAT-015｜发现总数与筛选数展示
- 归属：REQ-015｜PAGE-001｜FLOW-002｜Must
- 价值：用户能区分"没扫到"和"被筛掉"。
- 前置：FEAT-010/014。输入：集合与筛选配置。输出："发现 N 台 · 筛选后 M 台"同时展示。
- 正常：两数字实时更新。错误恢复：无。
- 平台差异：无。数据来源：设备集合。
- 依赖：无。安全隐私：无。
- 性能：随列表刷新。测试：TEST-P-001、TEST-A-005、TEST-W-007｜E4→E5｜发布条件：随 FEAT-010。

#### FEAT-016｜Smart HID 历史紧凑入口
- 归属：REQ-052（入口部分）｜PAGE-001→PAGE-004｜FLOW-011｜Must（形态见 DEC-012，推荐最近 1 台 + "全部历史"）
- 价值：老用户从扫描页直达配过的设备，但完整列表只在 PAGE-004。
- 前置：历史非空。输入：点击紧凑条目/全部历史。输出：→PAGE-003 详情 / →PAGE-004。
- 正常：紧凑区最多显示最近 1 台与总数。错误恢复：无（本地数据）。
- 边界（冻结，TP-G0-R1）：本入口**只读**——仅"查看详情"与"全部历史"两个动作；不提供删除、批量管理、TTL 修改或重命名；历史管理唯一归 PAGE-004（FEAT-061）。
- 平台差异：无。数据来源：DATA-006。
- 依赖：Smart HID Profile 注册。安全隐私：仅非敏感字段。
- 性能：本地同步读。测试：TEST-P-001、TEST-P-004、TEST-W-008｜E4｜发布条件：随 Smart HID 状态（DEC-006）。

## 6. CONN 连接

#### FEAT-020｜连接 attempt 与去重
- 归属：REQ-019｜PAGE-001→006｜FLOW-004｜Must
- 价值：连点不出并发连接；连接前自动停扫描。
- 前置：设备已发现。输入：deviceId。输出：连接中状态 → 建立会话。
- 正常：10s 超时（NFR-008）。错误恢复：失败→ERR-CONN-01 + 重试；同设备并发请求合并。
- 平台差异：无语义差异。数据来源：平台连接 API（经 Runtime）。
- 依赖：无。安全隐私：无。
- 性能：连接 ≤10s。测试：TEST-I-003、TEST-P-006、TEST-A-006、TEST-W-007、TEST-E-002｜E2→E5｜发布条件：夹具连接 E5 通过。

#### FEAT-021｜服务/特征发现
- 归属：REQ-019｜PAGE-006｜FLOW-004｜Must
- 价值：GATT 树是调试的地图。
- 前置：已连接。输入：会话。输出：服务/特征树（含属性标记）。
- 正常：树完整展示。错误恢复：发现失败关闭半开连接（ERR-CONN-02）。
- 平台差异：无。数据来源：平台发现 API。
- 依赖：无。安全隐私：无。
