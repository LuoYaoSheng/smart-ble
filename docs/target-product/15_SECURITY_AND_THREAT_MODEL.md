## 1. 本文负责什么 / 不负责什么

本文负责：资产清单、威胁模型（BLE/二维码/凭据/日志/OTA/下载供应链/外链/Smart HID）、缓解措施（SEC-001~019）、残余风险与安全测试规划。

本文不负责：具体实现（`10`~`13`）；披露流程细节（`19`）。

---

## 2. 资产与信任边界

| 资产 | 位置 | 信任边界 |
|---|---|---|
| Wi-Fi 密码 / Pairing token / MQTT 凭据 | 设备与用户手机内存 | 绝不出本地内存（token 生命周期 5 分钟） |
| 本地历史与日志 | 设备本地 storage | 无云；导出即出边界→脱敏 |
| BLE 空口数据 | 射频 | 公开（假设可被监听/伪造） |
| 夹具固件与串口 | 开发桌 | 物理可信 |
| Release 产物与页面 | 公网 | 不可信（假设被审查/篡改尝试） |
| 仓库与 CI | GitHub/Gitee | 凭据保护范围 |

## 3. 威胁模型与缓解

| # | 威胁 | 场景 | 缓解（SEC） | 残余风险 |
|---|---|---|---|---|
| T1 | 假 BLE 设备/恶意广播 | 仿冒夹具或 SHID 广播诱导连接 | SEC-003（二次身份确认）；夹具本身无敏感数据 | 低：误连不泄漏数据 |
| T2 | 恶意广播字段（超长/畸形） | 解析崩溃 | SEC-004（防御式解析+长度上限）；解析纯函数 | 低 |
| T3 | Pairing QR 泄露/重放 | token 被截图或复用 | SEC-007（仅内存+5 分钟一次性；服务端 409/410 语义） | 中：物理截屏不可防 |
| T4 | Wi-Fi 密码泄漏 | 日志/导出/URL | SEC-005/006（双段脱敏+URL 禁令） | 低 |
| T5 | 配网嗅探/篡改 | V1 明文 BLE write，无机密性与设备认证 | SEC-009（明文风险提示+最短暴露时间+后续升级路径） | 高（R-HID-01）：V1 取舍 |
| T6 | 日志/截图泄敏 | 证据包公开 | SEC-006（脱敏+抽查） | 低 |
| T7 | OTA 恶意固件/降级/中断 | 向夹具刷恶意镜像 | SEC-010（测试夹具定位声明+版本回读+abort 一致性）；无签名（明示限制） | 中（R-OTA）：接受，因非生产设备 |
| T8 | 下载供应链 | APK/固件被替换 | SEC-012（SHA256 展示+校验工具+E6 验证） | 低 |
| T9 | 恶意外链/二维码 | 落地页链到恶意站 | SEC-013（链接白名单+自动检查） | 低 |
| T10 | Smart HID 控制链滥用 | HID 设备被用于恶意输入 | SEC-011（控制链不在本产品；文档声明 V1 不支持清单；token/lease/ttl 由外部正典保证） | 范围外（外部系统） |
| T11 | 权限滥用 | App 申请多余权限 | SEC-001（最小权限） | 低 |
| T12 | 设备标识追踪 | MAC/deviceId 上送 | SEC-002（无云端上送） | 低 |
| T13 | 本地数据残留 | 卸载/移除后残留 | SEC-008（本地存储随卸载清除；移除彻底删除） | 低 |
| T14 | CI/构建凭据泄漏 | workflow 泄密 | SEC-014（ secrets 最小化+产物签名校验） | 低 |
| T15 | 落地页 XSS/注入 | 用户可控内容 | SEC-013（静态生成+无用户输入回显） | 低 |
| T16 | 错误消息泄敏 | 错误详情带凭据 | SEC-005（错误消息过脱敏） | 低 |

## 4. 安全要求登记（SEC-001~019）

| ID | 要求 | 验证 |
|---|---|---|
| SEC-001 | 最小权限：仅按能力检测申请 BLE 所需权限；不预取定位，仅环境要求时申请（DEC-003），无多余申请 | TEST-A-001/W-001/W-004 + manifest 审查 |
| SEC-002 | 设备标识（deviceId/MAC）不出本机 | 代码审查+网络面审查（无云端） |
| SEC-003 | 弱匹配设备必须二次身份确认；失败即断开 | TEST-H-001 |
| SEC-004 | URL/分享路径禁带敏感字段；广播解析防御式 | TEST-C-005、TEST-U-008 |
| SEC-005 | 错误消息与日志条目过脱敏规则表 | TEST-U-013 |
| SEC-006 | 日志导出与证据媒体发布前脱敏（脚本+人工） | TEST-R-004 |
| SEC-007 | Pairing token 仅内存；密码不落盘不展示（掩码除外） | TEST-U-015、TEST-I-009 |
| SEC-008 | 无云端个人数据；本地数据可删；卸载即清除（声明） | 隐私声明+TEST-P-004 |
| SEC-009 | Smart HID INPUT 仅经加密链路写入 | TEST-H-002 + 固件对账 |
| SEC-010 | OTA 无签名如实声明；版本回读为成功必要条件；abort 两端一致 | TEST-E-007、`18` 限制清单 |
| SEC-011 | Smart HID 控制链（MQTT/USB HID）不在本产品声明范围；V1 不支持清单对外一致 | TEST-R-007 文案检查 |
| SEC-012 | 公开产物必须 SHA256+可校验；E6 链接矩阵 | TEST-R-001/002/008 |
| SEC-013 | 外链白名单+自动可达性检查；静态站无用户输入回显 | TEST-R-005 |
| SEC-014 | CI secrets 最小化；无 secrets 入日志 | workflow 审查 |
| SEC-015 | 隐私声明公开可达（关于页+落地页） | TEST-R-005 |
| SEC-016 | 安全披露渠道（SECURITY.md+私密通道）公开 | TEST-R-005 |
| SEC-017 | 固件串口输出无敏感数据 | 串口日志审查 |
| SEC-018 | 证据包无真实凭据（token/密码/MQTT） | TEST-R-004 |
| SEC-019 | OTA 固件包完整性与目标校验（DEC-016）：传输前校验 manifest 格式/target/hardware/version/size/SHA256，错误包不进入事务；commit 阶段设备复核 size+SHA256 才 success；包校验防"刷错包/坏包"（签名验证为后续版本方向，V1 如实声明） | TEST-U-016、TEST-I-010、TEST-E-007 |

## 5. 残余风险登记

| ID | 残余风险 | 等级 | 处置 |
|---|---|---|---|
| R-HID-01 | Smart HID V1 明文配网可被近场嗅探或篡改 | 高 | 文档如实声明；缩短广播/配网窗口；外部正典后续升级 |
| R-OTA | 夹具 OTA 无固件签名 | 中 | 测试夹具定位声明；不用于生产 |
| R-QR | token 物理截屏不可防 | 低 | 5 分钟一次性+一次性消费 |

完整风险运营视图见 `21`（RISK-001~016）。

## 6. 验收条件与关联测试规划

- 16 类威胁有缓解或明示范围外；
- SEC-001~018 全部有验证方式；
- 残余风险如实登记不隐藏。

关联计划测试：`TEST-U-013/015`、`TEST-I-009`、`TEST-H-001/002`、`TEST-E-007`、`TEST-R-001/002/004/005/007/008`。
